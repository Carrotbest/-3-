# R53 — 자료 덱 재설계: 클래식 코버플로우 · 배경/넘버링 제거 · 자동 넘김 복구

대상(쓰기): `src/components/cards/MaterialDeck.tsx`(덱 표현 + 모션), `src/components/cards/CoverflowGallery.tsx`(HOME 덱).
무변경: `src/routes/{TS,Study,Home}.tsx`, export명·props 시그니처.

## 배경 (사용자 피드백)
R49~R50으로 만든 덱이 요구와 어긋난다. 사용자 지적 그대로:
1. **마우스 위치에 따른 자동 카드 넘김이 아예 동작하지 않는다.**
2. **화면을 와이드하게 채우지 못한다** — 카드가 가운데 좁게 몰려 있고 좌우가 비어 보인다.
3. **덱 배경(그라데이션)과 중앙 큰 넘버링을 아예 삭제**하고 싶다.
4. 카드 배치를 **클래식 코버플로우**(첨부 레퍼런스)로 되돌린다.
5. **메인 카드 외 나머지는 작게, 다만 내용이 살짝 보이게(불투명도 60% 수준).**

## Task 1 ★ — 자동 넘김 복구 (최우선, 확실하게)
현재 `useCoverflowMotion`의 마우스 위치 자동 넘김이 실사용에서 동작하지 않는다. 아래를 **모두** 점검·수정한다.

**원인 후보와 조치**
- **포커스 락**: `onFocus`에서 `focusedRef.current = true` 후 `stopAuto()`, `onBlur`에서만 해제. React의 `onFocus`는 focusin이라 **자식(카드 버튼)에 포커스가 가면 덱 전체 자동 넘김이 꺼지고 복구되지 않는다.** → **포커스로 자동 넘김을 끄지 말 것.** 굳이 필요하면 `:focus-visible`(키보드 탐색)일 때만 일시 정지하고, 마우스가 다시 움직이면 즉시 재개한다.
- **핸들러 부착 위치**: `onPointerMove`는 **덱의 가장 바깥 컨테이너**(카드가 놓인 무대 전체를 덮는 요소)에 붙인다. 카드 위에서도 이벤트가 죽지 않도록 카드에 `pointer-events`를 제한하지 말 것(카드 클릭은 유지하되 move 이벤트는 부모까지 버블).
- **좌표 기준**: `event.currentTarget.getBoundingClientRect()` 기준 상대 X. 핸들러가 붙은 요소가 무대 전체를 덮는지 확인(폭이 0이거나 좁으면 오작동).
- **rAF 루프**: 탭 비활성 시 rAF가 멈추는 것은 정상이나, **탭 복귀 시 자동으로 재개**되어야 한다(`visibilitychange`에서 정지만 하고 재개 로직이 없으면 마우스를 다시 움직여야 살아난다 — 허용).
- **정지 조건은 딱 3가지만**: ① dead zone 진입 ② `pointerleave`(무대 이탈) ③ `prefers-reduced-motion`. 그 외 사유로 멈추지 말 것.

**동작 사양(R50 유지)**
- 상대 X → `d = (x-0.5)*2`. `|d| < 0.12` = dead zone(감속 후 가장 가까운 카드로 스냅 정지).
- 그 밖: `t = (|d|-0.12)/0.88`, `velocity = sign(d) * (MIN_V + (MAX_V-MIN_V) * t²)`, `MIN_V=1.2`, `MAX_V=9`(카드/초).
- 매 프레임 `pos += velocity * dt`(dt 상한 0.05s), 속도는 목표값으로 보간(lerp 0.18)해 부드럽게. **한 장씩 끊기는 이동 금지.**
- 경계(처음/끝)에서 정지.

**구현 후 자가 검증 필수**: 브라우저에서 마우스를 무대 오른쪽 끝 → 가운데 → 왼쪽 끝으로 옮기며 **연속으로 흐르다 가운데서 멈추는지** 반드시 눈으로 확인할 것.

## Task 2 — 배경·넘버링 삭제
- 무대의 **radial-gradient 배경 제거**(활성 팔레트 기반 글로우 전부 삭제). 배경은 카드 컨테이너와 동일한 평면(`var(--card)` 또는 투명).
- **중앙 큰 인덱스 오버레이(`NN` / `of 06`) 완전 삭제.**
- 상단에 남아 있는 활성 항목 텍스트 블록(제목·요약·날짜)은 **유지**(레퍼런스처럼 카드 아래 또는 위에 활성 항목명 표시). 단 높이를 최소화한다.
- 하단 컨트롤: 화살표는 유지. **dot indicator는 유지하되 과하지 않게**(항목이 많으면 R50의 창/진행바 규칙 유지).

## Task 3 — 클래식 코버플로우 배치 (레퍼런스 기준)
첨부 레퍼런스처럼 **가운데 카드가 정면으로 크게, 좌우로 갈수록 3D로 기울며 작아지는** 형태로 바꾼다.

- **표시 장수**: TS·STUDY 덱 = **7장**(중앙 1 + 좌우 각 3), HOME 덱(`CoverflowGallery`) = **5장**(중앙 1 + 좌우 각 2). 상수로 분리해 각 컴포넌트가 다른 값을 쓰게 한다.
- 거리 `k = index - center`(정수 아닌 연속값 허용, 현재 `posRef` 기반 유지):
  - **X 위치**: 중앙에서 멀어질수록 간격이 좁아지게(겹침) — 예 `x = sign(k) * (BASE * (1 - Math.exp(-|k| * 0.55)))` 또는 단순 누적 간격 감소. **좌우 끝 카드가 무대 가장자리까지 닿아 화면을 꽉 채울 것**(피드백 2번 해결).
  - **회전**: `rotateY = -sign(k) * min(|k|,3) * 32deg` 정도(중앙 0°, 바깥으로 갈수록 기울어짐). `perspective`는 무대에 `1200px` 유지.
  - **크기**: `scale = 1 - min(|k|,3) * 0.14`(중앙 1.0 → 바깥 약 0.58).
  - **불투명도**: 중앙 1.0, **그 외 0.6**(피드백 5번: 내용이 살짝 보여야 함). 완전히 흐려서 안 보이면 안 된다. 3장 초과 거리부터 0으로 페이드아웃.
  - **z-index**: 중앙이 최상단, 거리순 하강.
- **카드 내용은 모든 카드에 렌더**한다(제목·요약·날짜). 측면 카드도 축소된 상태로 내용이 보여야 한다(불투명도 60%). 빈 카드/색 바만 보이는 현상 금지.
- 카드 자체는 **흰 배경 유지**(`var(--card)`, `var(--border)`), 팔레트는 상단 얇은 컬러 바 등 액센트로만(R49 방침 유지).

## Task 4 — 와이드하게 채우기
- 무대 폭을 컨테이너 100%로 쓰고, 좌우 패딩을 최소화한다.
- 카드 폭을 키운다: 예 `clamp(200px, 22%, 300px)`. 7장이 겹치며 무대 전체를 채우도록 X 간격과 함께 조정.
- 무대 높이는 R50의 축소 기조 유지(낮고 넓은 띠). 카드가 잘리지 않는 선에서 최소 높이.
- **HOME(`CoverflowGallery`)은 5장 기준으로 별도 치수** — 홈 레일 폭에 맞춰 더 컴팩트하게. TS/STUDY 수치를 그대로 쓰지 말 것.

## 금지사항
- 새 npm 패키지 금지(framer-motion 등). 기존 rAF/CSS transform만.
- `TS.tsx`·`Study.tsx`·`Home.tsx` 및 export 시그니처 변경 금지.
- 포커스를 이유로 자동 넘김을 영구 비활성하지 말 것. `setInterval` 한 칸 이동 방식 부활 금지.
- `prefers-reduced-motion` 대응 필수(자동 넘김 비활성, 카드는 정적으로 보임 — 빈 화면 금지).
- 커밋 금지.

## 검증(구현 후 자기점검)
1. `tsc --noEmit && vite build` 통과.
2. `#/study`에서 **마우스를 무대 오른쪽에 두면 카드가 끊김 없이 연속으로 흐르고**, 가운데로 오면 감속 후 멈춘다. 왼쪽은 역방향. **카드를 클릭했다가 다시 마우스를 옮겨도 계속 동작한다**(포커스 락 없음).
3. 덱 배경 그라데이션과 중앙 큰 넘버링이 **화면에서 사라졌다**.
4. 중앙 카드가 크고 정면, 좌우 카드는 기울며 작아지고 **내용이 60% 불투명도로 보인다**. TS/STUDY 7장, HOME 5장.
5. 좌우 끝 카드가 무대 가장자리까지 닿아 **가로를 꽉 채운다**.
6. 화살표·dot 수동 이동, 카드 클릭 상세 정상.
