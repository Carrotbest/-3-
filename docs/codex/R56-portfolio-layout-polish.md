# R56 — PORTFOLIO 레이아웃 정리: 오버뷰 보강 · 높이 축소/고정 · 좌우 리사이저 · 그라데이션 막대

대상(쓰기): `src/routes/Portfolio.tsx`, `src/data/chemical.ts`(집계 추가), 필요 시 `src/index.css`.
무변경: `portfolio-store.ts` 어댑터 인터페이스, `PortfolioForm.tsx` 저장 로직, `Home.tsx` 호출부.

## 배경 (사용자 피드백, 실데이터 24건 기준 화면)
1. **OVERVIEW 패널에 빈 공간이 많다** → 채울 데이터를 구성해 추가.
2. CATEGORY MIX는 이미 스크롤이 있으니 **칼럼 세로 길이를 현재의 70% 수준으로 축소**.
3. **카테고리 문자열이 전부 잘린다**(`Anti-bacterial ...`) → **섹션 간 간격을 수동 조절할 수 있는 라인(리사이저)** 제공.
4. 카테고리별 개발 단계 **막대를 그라데이션으로 부드럽게**.
5. **칼럼 전체 형태를 고정** — 카테고리를 바꿀 때 카드 개수에 따라 칼럼 크기가 달라져 거슬린다.

---

## Task 1 — OVERVIEW 빈 공간 채우기 (실제 보유 데이터로만)
현재 OVERVIEW에는 전체 건수·완료율 도넛·단계 스택바·검증통과·연결원단뿐이라 하단이 비었다. **엑셀에 실제로 있는 값**으로만 구성한다(가짜 지표 금지).

추가할 블록(공간에 맞게 2~4개 선택, 우선순위 순):

**① FL 등록 연도별 추이 ★ (가장 유용)**
- 근거: FL 번호 72건이 `FL`+**YY**+MM+4자리 형식이며 실제로 **2020~2026년**에 분포한다. `flNos`에서 연도(`YY`)를 파싱해 연도별 건수를 집계.
- 표현: 소형 바 차트 또는 스파크라인(연도 축). "팀의 기능성 개발 이력"을 한눈에 보여준다.
- `chemical.ts`에 `flYearDistribution(portfolio): { year: string; count: number }[]` 추가.

**② 기술 유형 비율**
- 항목 태그(`Chemical Tech` / `Yarn Tech` 등 현재 카드에 표시 중인 분류)로 비율 집계 → 도넛 또는 가로 스택바 1줄.
- 태그가 없는 항목은 `기타`로.

**③ 기능 커버리지 요약**
- 전체 기능 카테고리 수 대비 **완료 건을 1건 이상 보유한 기능 수**(예 `14개 기능 중 9개 검증 자산 보유`). 한 줄 지표 + 미니 진행바.

**④ 최근 업데이트**
- 웹 등록분(`source==="web"`)의 `updatedAt` 최신 3건을 목록으로(제목 + 상태 배지 + 날짜). 없으면 블록 자체를 숨긴다(빈 껍데기 금지).

- 각 블록은 `Reveal` + `NumberTicker startOnView` 등 기존 모션 관례 사용.

## Task 2 — 칼럼 세로 길이 축소 + 고정 ★
- 두 패널(OVERVIEW / CATEGORY MIX)의 **높이를 현재의 약 70%로 축소**한다. CATEGORY MIX는 이미 내부 스크롤이 있으므로 축소해도 정보 손실이 없다.
- **높이를 고정값으로 못 박는다**: 예 `h-[clamp(20rem, 38vh, 26rem)]` 같은 고정 높이 + 내부 `min-h-0 overflow-y-auto`. **콘텐츠 양에 따라 높이가 변하면 안 된다.**
- **카드 그리드 영역도 고정 프레임**: 카테고리를 바꿔 카드 수가 1개든 9개든 **아래 영역의 높이·폭이 흔들리지 않게** 한다.
  - 카드 목록 컨테이너에 **최소 높이**를 주고(예 `min-h-[32rem]`), 내부에서 스크롤/여백 처리.
  - 카드 그리드는 고정 열 수(`sm:2 / xl:3`)로 유지하고, 항목이 적을 때 카드가 늘어나지 않도록 `auto-rows` 또는 `items-start` 사용.
  - 결과: 카테고리 전환 시 **레이아웃 점프(layout shift)가 없어야 한다.**

## Task 3 — 좌우 섹션 리사이저(수동 간격 조절) ★
카테고리 문자열이 잘리는 문제를 사용자가 직접 해결할 수 있게, **두 패널 사이에 드래그 가능한 구분선**을 넣는다.
- 좌(OVERVIEW) / 우(CATEGORY MIX) 사이에 **세로 스플리터 핸들**(폭 6~8px, hover 시 색 강조, `cursor: col-resize`).
- 드래그로 좌우 비율 조절. 범위 제한(예 좌측 30%~70%).
- **`localStorage`에 비율 저장**해 새로고침 후에도 유지(키 예 `portfolio-split`).
- 접근성: 핸들에 `role="separator"`, `aria-orientation="vertical"`, `aria-valuenow`(%) 부여. **키보드 좌/우 화살표로도 조절** 가능하게.
- 더블클릭 시 기본 비율로 초기화.
- **앱에 이미 유사 구현이 있다**: DD MASTER의 열 너비 드래그(R33/R40). 그 구현 방식·감성을 참고해 일관되게 만들 것.
- 모바일(좁은 화면)에서는 스플리터를 숨기고 세로 스택으로 전환.

## Task 4 — 카테고리 이름 잘림 완화
리사이저와 별개로, 기본 상태에서도 덜 잘리게:
- 영문명은 `truncate` 유지하되 **`title` 속성으로 전체 문자열 툴팁** 제공(hover 시 확인 가능).
- 한글명은 되도록 한 줄에 다 보이게(폰트 크기 소폭 축소 허용).
- 막대 영역과 라벨 영역의 비율을 조정해 라벨 폭을 조금 더 확보(예 라벨 최소 폭 확보 후 막대가 남은 공간 사용).

## Task 5 — 막대 그라데이션
- CATEGORY MIX의 단계 스택 막대를 **평면 단색 → 부드러운 그라데이션**으로.
- 각 단계 색(`--stage-plan/progress/done`)을 기준으로 `linear-gradient(90deg, color, color-mix(in oklab, color 78%, white))` 형태의 은은한 밝기 변화. **과한 채도·무지개 금지**(원본 HTML의 절제된 톤 유지).
- 경계는 살짝 둥글게(`rounded-full`) 하고, 세그먼트 사이에 1px 간격을 줘 부드럽게 분리.
- OVERVIEW의 단계 스택바도 동일 처리로 통일.
- 채움 애니메이션(`useInView` 게이트 + `transition-[width]`)은 유지.

## 금지사항
- 실제 데이터에 없는 지표를 만들어내지 말 것(추정·가짜 KPI 금지). 데이터가 없으면 블록을 숨긴다.
- `portfolio-store.ts` 어댑터 인터페이스 변경 금지(Firebase 전환 대비). `PortfolioForm` 저장 로직 변경 금지.
- 새 npm 패키지 금지. 실데이터(협력사·브랜드·FL) 저장소 커밋 금지 — 데모는 익명 유지.
- 인라인 카드 확장 부활 금지(모달 유지). 하단 커버리지 섹션 부활 금지.
- `prefers-reduced-motion` 대응 유지. 커밋 금지.

## 검증(구현 후 자기점검)
1. `tsc --noEmit && vite build` 통과.
2. OVERVIEW 하단 빈 공간이 **실데이터 기반 블록**(FL 연도 추이 등)으로 채워진다.
3. 두 패널 높이가 이전 대비 **약 70%**이고, **콘텐츠 양과 무관하게 고정**이다.
4. 카테고리를 여러 번 바꿔도 **칼럼 크기·레이아웃이 흔들리지 않는다**(카드 1개 ↔ 9개 전환 시 확인).
5. 두 패널 사이 **드래그 핸들로 좌우 폭 조절**이 되고, 새로고침 후 유지된다. 키보드 화살표로도 조절된다.
6. 카테고리 라벨 hover 시 전체 이름 툴팁이 보인다.
7. 막대가 그라데이션으로 부드럽게 표시된다(단계 색 유지).
