## 1. 육면체 표지

`roomFlag`의 `CylinderGeometry(1.05, 1.05, 0.92, 6, 1, true)`와 테두리 고리 둘을 **지운다.** 대신 `BoxGeometry`를 쓴다.

### 치수

**글자 길이에 따라 가로가 달라진다.**

- 캔버스 한 면은 **512 × 192**다.
- 글자 크기는 **86px 고정**이다. 줄이지 마라. 시인성이 이번 지시의 핵심이다.
- `measureText`로 이름 폭을 잰다. 좌우 여백 56을 더한 값이 그 면의 실제 폭이다.
- 월드 가로 `width`는 `면 폭 / 170`이다. **최소 2.0, 최대 5.2**로 묶는다.
- 세로 `height`는 **0.9**, 두께 `depth`는 **0.9**로 고정이다.
- 기둥은 지금처럼 높이 4.4, 굵기 0.06, 그 방 `ROOM_ACCENT` 색이다. 육면체는 `y = 3.9`다.

### 면마다 다른 재질

`BoxGeometry`는 재질 배열 여섯을 받는다. 순서는 `[+x, -x, +y, -y, +z, -z]`다.

| 면 | 무엇을 |
|---|---|
| `+x`, `-x` | **옆 캔버스.** 세로 면이라 가로가 `depth`다. 깊이용 캔버스를 따로 그린다 |
| `+z`, `-z` | **정면 캔버스.** 가로가 `width`다 |
| `+y` | **윗면 캔버스.** 항공샷에서 읽히는 면이다 |
| `-y` | 단색. 그 방 `ROOM_ACCENT`를 검정과 0.3으로 섞은 값 |

- 정면 캔버스는 512 × 192, 옆 캔버스는 192 × 192(이름이 길면 두 줄로 접는다), 윗면 캔버스는 512 × 512다.
- **윗면 글자는 두 번 그린다.** 가운데 가로로 한 번, 그 아래 180도 돌려 한 번이다. 어느 쪽에서 내려다봐도 한쪽은 바로 읽힌다.

### 빛나게

- 재질은 전부 `MeshBasicMaterial`이다. 조명을 안 받아 **스스로 밝다.** `MeshLambertMaterial`로 바꾸지 마라.
- 바탕은 **흰색**이고 글자는 그 방 `ROOM_ACCENT`다. R406은 반대였다. 흰 바탕이 조명 기구처럼 보인다.
- 테두리에 폭 10짜리 `ROOM_ACCENT` 띠를 두른다.
- 육면체 **아래에 빛 번짐 판**을 하나 깐다. 가로 `width * 1.6`, 세로 `depth * 1.6`, `y = 3.4`, 수평, 그 방 색, 투명도 0.18, `depthWrite: false`다. 조명 기구 아래 빛처럼 보인다.
- **광륜(`AdditiveBlending`)은 쓰지 마라.**

### 바닥 그림자

지금 2.2 × 2.2다. `width * 0.8` × `depth * 2.4`로 바꾼다.

## 2. 섹션 간판을 양면으로

지금 `neonSign`이 앞면 한 장이다. 뒤에서 보면 안 보인다.

- 글자면을 **둘** 만든다. 앞면은 지금 그대로 `z = 0.09`, 뒷면은 `z = -0.09`에 두고 `rotation.y = Math.PI`를 준다.
- **같은 캔버스를 쓴다.** 180도 돌리면 글자가 바로 읽힌다. 캔버스를 좌우 반전해 새로 그리지 마라.
- 뒤판은 지금 두께 0.12다. **0.2로 키운다.** 양면 사이에 두께가 있어야 한다.

## 3. 육면체를 눌러 들어간다

### 선택 방법을 바꾼다

- **육면체가 방 선택의 유일한 입구다.** 방 바닥이나 가구를 눌러도 방이 선택되지 않는다.
- 육면체 메시에 `userData = { kind: "room", id: room.path }`를 단다. `pickables`에 넣는다.
- **방 전체를 덮던 히트박스(`hit.scale.set(room.w, 3.6, room.d)`)의 `kind`를 `"floor"`로 바꾼다.** 선택된 방 안에서 걷기 클릭을 받는 데만 쓴다. 선택 전에는 아무 일도 안 한다.
- 선택 해제는 빈 바닥(어느 방에도 안 속한 자리)을 누르거나 Esc다. 지금 그대로다.

### 집중 보기

방을 고르면 **그 방만 남긴다.**

- 고른 방이 아닌 `roomGroups`의 그룹은 **`visible = false`**로 통째로 숨긴다. 재질을 흐리게 하는 지금 방식(`setRoomDimmed`)보다 싸고 확실하다. `setRoomDimmed` 호출은 지운다(함수는 남겨 둬도 된다).
- **공용 구역 넷, 섹션 격벽, 섹션 간판, 통로 화분도 숨긴다.** 이것들을 한 `THREE.Group`(`sceneDecor`)에 모아 두고 그 그룹의 `visible`만 끈다. 지금은 `scene`에 흩어져 있으니 모아라.
- **외벽과 바탕 바닥은 남긴다.** 다 숨기면 허공에 뜬다.
- 고른 방의 룸 표지 육면체는 **숨긴다.** 들어간 방의 간판은 필요 없고 시야를 가린다.
- 사람 아바타는 숨기지 마라. 다른 방 사람도 그대로 둔다.

### 줌

- `focusAt`의 줌 계산을 바꾼다. 지금 `46 / max(w, d)`라 큰 방이 거의 안 커진다.
- **짧은 변 기준으로 방이 화면의 0.82를 채우게** 한다. `resize`가 쓰는 `frame` 값을 모듈 스코프에 두고, `zoom = frame * 0.82 / Math.max(room.w, room.d)`로 계산한다. `maxZoom`을 **12**로 올린다.
- 카메라 타깃을 그 방 중심으로 옮긴다. 지금 그대로다.

## 4. 화면을 꽉 채운다

### 자리

`Meta.tsx`의 그리드다.

- 지금 `lg:grid-cols-[minmax(0,1fr)_300px]`에 캔버스 높이가 `clamp(380px, 60vh, 620px)`다.
- 높이를 **`calc(100vh - 230px)`**로 바꾸고 최소 `420px`를 둔다. 좁은 화면은 `clamp(280px, 86vw, 520px)` 그대로다.
- 머리말(`header`)의 위아래 여백을 줄여라. `py-3`을 `py-2`로, 바깥 `space-y-5`를 `space-y-3`으로 한다.
- 오른쪽 패널은 300px 그대로다. 지우지 마라.

### 기본 시점

- **위에서 45도, 정면이다.** 극각은 `Math.PI / 4`(45도), 방위각은 0이다.
- `camera.position`을 타깃 `(0, 0, -2)` 기준으로 `(0, d, d)` 꼴로 둔다. `d = 70`이면 `camera.position.set(0, 70, 68)`이다.
- **처음 열 때 전체가 꽉 차게 줌을 맞춘다.** 바닥이 82 × 58이므로 `resize`에서 `camera.zoom`을 `frame * 0.94 / 58`로 잡고 `controls.update()`를 부른다. 창 크기가 바뀌면 다시 맞춘다. **단 사용자가 줌을 손댄 뒤에는 다시 맞추지 마라.** `controls`에 `change` 리스너를 달아 사용자가 건드렸는지 표시를 남긴다.
- 극각 범위는 지금(0.45~1.25) 그대로 둔다. 기본값만 45도다.

## 5. 이동을 스페이스로

- `controls.mouseButtons.LEFT`를 기본 `THREE.MOUSE.ROTATE`로 둔다.
- `keydown`에서 `event.code === "Space"`면 `LEFT`를 `THREE.MOUSE.PAN`으로 바꾸고, `keyup`에서 `ROTATE`로 되돌린다. **입력칸에 포커스가 있으면 건너뛴다.** 지금 `handleKeyDown`에 그 가드가 이미 있다.
- 스페이스로 화면이 스크롤되지 않게 `preventDefault`를 건다.
- `window`가 포커스를 잃으면(`blur`) `ROTATE`로 되돌린다. 눌린 채로 굳지 않게 한다.

### 안내 문구

`Meta.tsx`의 캔버스 상자 **아래 한 줄**이다. 캔버스 안에 겹치지 마라.

> 끌기로 돌리고, 스페이스를 누른 채 끌면 화면이 움직입니다. 휠로 확대합니다. 육면체 표지를 누르면 그 방으로 들어갑니다.

글자는 `text-[11px] text-[var(--muted-foreground)]`다.

## 6. 가구를 실제처럼

### 다리가 없다

`deskUnit`의 의자가 좌판과 등판 두 장뿐이라 공중에 떠 있다. **아래 가구에 다리와 받침을 더한다.**

| 가구 | 더할 것 |
|---|---|
| `deskUnit` 의자 | 좌판 아래 기둥 하나(반지름 0.045, 높이 0.36, `y = 0.23`)와 받침 별(반지름 0.26 원기둥 높이 0.04, `y = 0.03`). 다리 다섯은 과하다 |
| `benchRow` 의자 | 같은 기둥과 받침 |
| `meetingTable` 의자 | 같은 기둥과 받침 |
| `/rdda` 좌석 | 인스턴스라 다리를 못 단다. 좌판 `y`를 0.46에서 0.44로 낮추고 **받침 인스턴스 한 벌을 더한다**(반지름 0.2, 높이 0.05, `y = 0.025`) |
| `sofaSet`, `armchair` | 네 귀에 높이 0.12 짧은 다리(반지름 0.04) |
| `cabinet` | 바닥에 높이 0.06 받침대(가로 1.4, 두께 0.46) |
| `bookshelf` | 같은 받침대(가로 2.0, 두께 0.4) |
| `shelfDivider` | 같은 받침대(가로 4.1, 두께 0.42) |
| `coffeeTable` | 다리 셋(반지름 0.04, 높이 0.4) |
| `displayPedestal` | 바닥에 받침 테 |

**치수를 바꾸지 마라.** 다리를 더하는 것이지 가구를 키우는 것이 아니다.

### 화면을 더 자세하게

`screenCanvasFor`의 셋을 손본다.

- `grid`: 머리줄에 칸 구분 세로선 넷을 긋고, 줄마다 오른쪽 끝에 작은 상태 점(초록, 주황, 빨강을 번갈아)을 찍는다.
- `chart`: 막대 위에 숫자 자리 대신 가는 가로 눈금선 셋을 깔고, 막대마다 꼭대기에 2px 밝은 띠를 둔다.
- `line`: 꺾은선 아래를 같은 색 투명도 0.12로 채운다. 꼭짓점마다 반지름 2.5 점을 찍는다.
- 셋 모두 **오른쪽 위에 작은 시계 모양**(반지름 5 원과 바늘 둘)을 넣는다. 켜진 화면으로 보인다.

### 벽

- **모니터 벽과 차트 패널 테두리에 베젤을 둔다.** 지금 `materials.dark` 한 장이라 납작하다. 테두리를 두께 0.04만큼 앞으로 뺀 네 조각으로 만들어라.
- `/trend/portfolio`의 액자 가벽에 **아래 걸레받이**(높이 0.12, 두께 0.16)를 더한다.

## 성능

다리와 받침이 는다. 육면체는 육각 기둥보다 면이 적다. **총 메시 3,500개 이하**를 지킨다. 작업 전이 1,572개다.

의자 받침과 기둥은 같은 가구 함수 안에서 만들어지므로 인스턴스로 못 묶는다. `/rdda` 좌석 받침만 `addInstanced`로 묶어라.

육면체 캔버스는 방마다 정면, 옆, 윗면 셋이다. 열일곱 방이면 쉰한 장이다. 크기가 작으니 그대로 둬도 된다.

만든 geometry, material, texture는 정리 단계에서 전부 `dispose()` 해라.
