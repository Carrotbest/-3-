# R401 — META 8단계: 가구를 한 방향으로 놓지 않는다

상태: 미착수.

2026-11-09 박향근 지시다. 참조 이미지를 한 장 받았다.

> "각 룸의 컴퓨터와 책상을 삐딱하게 하라는 뜻이 아니다. 가구 배치를 한방향으로 하지마라는 이야기다."

**R399가 틀렸다.** R399는 "섬마다 각도를 다르게 한다"면서 `rotation.y`를 `(index % 3 - 1) * 0.26` 라디안으로 줬다. 0도와 ±15도가 섞인다. 책상이 격자에서 비뚤어져 보일 뿐 방향이 갈리지는 않는다. **박향근이 원한 것은 비스듬한 각도가 아니라 서로 다른 방향이다.**

## 원칙

- 가구 각도는 **0, 90, 180, 270도 넷뿐이다.** 그 사이 각도를 쓰지 마라.
- **한 방에 가구가 두 방향 이상을 보게 한다.** 책상 섬이 둘 이상이면 같은 방향으로 놓지 마라.
- 벽을 따라 붙는 가구(캐비닛 줄, 화이트보드, 전시 벽)는 지금 방향 그대로다. 벽을 등지는 것이 맞다.

## 참조 이미지에서 가져올 것

받은 이미지는 아이소메트릭 가상 오피스다. 우리 씬과 같은 종류다. 아래 다섯이 지금 우리에게 없다.

1. **긴 공용 책상 줄.** 상판 하나에 좌석 여럿이 한쪽을 보고 늘어선다. 좌석 사이에 낮은 가림판이 있다. 지금 우리는 2 × 2 섬뿐이라 단조롭다.
2. **책장형 칸막이.** 책장이 벽에 붙지 않고 방 가운데 서서 공간을 가른다. 양면이 다 보인다.
3. **같은 방 안에서 갈리는 방향.** 한쪽은 책상이 남북을 보고 다른 쪽은 동서를 본다.
4. **크기가 다른 화분.** 큰 야자, 중간 화분, 책상 위 작은 화분 셋이 섞인다.
5. **라운지의 1인 소파.** 2인 소파와 1인 소파와 둥근 테이블이 한 묶음이다.

**가져오지 않을 것**: 발자국 무늬, 말풍선, 아바타 얼굴 그림. 우리는 행잉 사인과 이름표가 이미 있다.

## 대상

`src/components/meta/OfficeScene.tsx` 하나다. 다른 파일을 건드리지 마라.

## 1. `deskIsland`의 서명을 바꾼다

지금은 이렇다.

```
const deskIsland = (parent, x, z, index, seatCount = 4) => {
  const island = furnitureGroup(parent, x, z, (index % 3 - 1) * 0.26)
```

`index`를 `rotation`으로 바꾼다. 호출부가 라디안을 직접 넘긴다.

```
const deskIsland = (parent, x, z, rotation = 0, seatCount = 4) => {
  const island = furnitureGroup(parent, x, z, rotation)
```

**`(index % 3 - 1) * 0.26`을 지워라.** 호출부 일곱 곳을 새 서명에 맞춰라. 넘길 값은 `0`, `Math.PI / 2`, `Math.PI`, `-Math.PI / 2` 넷뿐이다.

## 2. 새 가구 둘

### `benchRow(parent, x, z, rotation, seats)`

긴 공용 책상이다. 회전 전 기준으로 **상판이 x축을 따라 눕고 앉는 사람은 +z 쪽에 선다.**

- 상판: 가로 `seats * 1.6`, 두께 0.09, 높이 1.05. 재질 `materials.desk`.
- 다리: 상판 양 끝에서 0.3 안쪽에 `materials.metal` 기둥 두 개. 굵기 0.12, 높이 1.05.
- 좌석마다(`index` 0부터):
  - 좌석 중심 x는 `(index - (seats - 1) / 2) * 1.6`이다.
  - 모니터 하나. `box(0.72, 0.46, 0.04, materials.screen, 좌석x, 1.4, -0.22)`. 살짝 안쪽을 보게 `rotation.y`를 0으로 둔다.
  - 의자 하나. `deskUnit`의 의자와 같은 치수다. 좌석 중심에서 `z = 0.95`와 `z = 1.21`이다.
- 좌석 사이 가림판: 좌석 경계마다 `box(0.06, 0.42, 1.0, materials.metal, 경계x, 1.26, -0.1)`. 좌석이 `seats`개면 경계는 `seats - 1`개다.
- 상판 뒤쪽 끝에 높이 0.45 등판: `box(seats * 1.6, 0.45, 0.07, materials.metal, 0, 1.27, -0.52)`.

### `shelfDivider(parent, x, z, rotation)`

방 가운데 서는 책장형 칸막이다. **`bookshelf` 두 개를 등 맞대어 흉내 내지 마라.** 양면이 뚫려 보이는 것이 참조 이미지의 모양이다.

- 몸통 틀: 가로 4.2, 높이 2.0, 두께 0.45.
  - 좌우 기둥 `box(0.08, 2.0, 0.45, materials.wood, ±2.06, 1.0, 0)`
  - 가로 선반 넷 `box(4.2, 0.07, 0.45, materials.wood, 0, 0.1 + shelf * 0.62, 0)`, `shelf`는 0부터 3까지
  - 세로 칸막이 둘 `box(0.07, 2.0, 0.45, materials.wood, ±0.7, 1.0, 0)`
- 칸은 3 × 3이다. 칸마다 책 **세 권**을 세운다. `box(0.12, 0.42, 0.26, 색, ...)`이고 칸 바닥에서 0.21 위다. 색은 `FABRIC_COLORS`에서 **번호 해시로** 고른다. 랜덤을 쓰지 마라.
- 책은 `addInstanced`로 한 번에 그려라. 칸당 3권 × 9칸 = 27개다.

## 4. 화분 크기를 셋으로 쓴다

`plantRow`가 지금 `1 + index % 2 * 0.16`으로 두 크기만 쓴다. **셋으로 늘린다.**

```
const PLANT_SIZES = [1, 1.45, 0.78]
```

`index % 3`으로 골라라. 참조 이미지처럼 큰 야자와 작은 화분이 섞여야 한다.

**책상 위 작은 화분을 더한다.** `deskIsland`와 `benchRow`의 상판 끝에 `plant(..., 0.4)` 하나씩이다. 섬마다 하나, 벤치마다 하나다.

## 하지 말 것

- **비스듬한 각도를 쓰지 마라.** 0, 90, 180, 270도 넷뿐이다. 이것이 이번 지시의 핵심이다.
- 방의 중심 좌표, `w`, `d`, `shape`를 바꾸지 마라.
- 섹션 격벽, 주 통로, 가지 통로, 조명, 카메라를 건드리지 마라.
- `facilities.ts`를 건드리지 마라. 이번에는 가구만 움직이고 시설 좌표는 그대로다. **다만 위 배치로 가구가 시설 좌표와 겹치면 가구를 비켜라.** 시설을 옮기지 마라.
- 랜덤을 쓰지 마라. 색과 좌표는 번호 해시로 정한다.
- 네온, 광륜, 천장, 후처리를 만들지 마라.
- 담당자 집계나 팀 묶음을 만들지 마라. 예시 사람을 만들지 마라.
- 외부 3D 파일, 이미지, 폰트를 불러오지 마라.
- 한글을 영어로 바꾸지 마라. 파일은 UTF-8이다.
- 코드를 한 줄로 눌러 담지 마라. 커밋하거나 푸시하지 마라.

## 성능

`benchRow`와 `shelfDivider`가 메시를 늘린다. 책 27개는 `addInstanced`로 묶어 하나로 센다. **총 메시 3,500개 이하**를 지킨다. 작업 전이 1,792개다.

만든 geometry, material, texture는 정리 단계에서 전부 `dispose()` 해라.

## 검증

1. `npm run build` 한 번. 1분 반쯤 걸린다.
2. `Meta` 청크 크기를 적어라. **작업 전 기준값이 `Meta` 10.91 kB, `OfficeScene` 557.49 kB다.** `Meta`가 12 kB를 넘으면 코드 분리가 깨진 것이다.
3. `git status --short`로 바뀐 파일이 `OfficeScene.tsx` 하나뿐인지 확인해라.
4. 개발 서버를 띄우지 마라. 로컬 5175에 이미 떠 있으니 건드리지 마라. 화면 확인은 박향근이 한다.

보고에는 방마다 가구가 몇 방향을 보는지 한 줄씩, 새 가구 둘의 메시 개수, 총 메시 개수, 청크 크기, 판단이 필요했던 지점만 적어라. 코드를 붙이지 마라.

## 실제 적용 결과 (2026-11-09)

코덱스 사용량 한도가 오후 2시까지라 박향근 판단으로 클로드가 시공했다.

### 지시서에서 달라진 것

- **`/study` 열람 테이블은 옮기지 않았다.** 지시서는 `meetingTable(group, 4, 0, 6)`을 `(6, 2.6)`으로 옮기라고 했는데, 옮긴 자리가 서가 두 줄과 겹친다. 회의 테이블 반지름이 2.3이고 서가가 z ±1.2에 x −8에서 8까지 늘어서 있어 22 × 10 안에서 비켜 둘 자리가 없다. **이 방은 가구 배치를 다시 짜야 손댈 수 있다.** 서가 간격을 줄이거나 열람 테이블을 하나로 줄이는 쪽이다.
- **책상 위 작은 화분을 넣으려고 `plant`에 `y` 인자를 더했다.** 기본값 0이라 기존 호출 전부가 그대로 돈다. 상판 높이 0.78에 크기 0.38짜리를 섬마다 하나, 벤치마다 하나 올렸다.
- `/` 로비 1인 소파는 `sofaSet`에 분기를 더하지 않고 `armchair` 함수를 따로 만들었다. `sofaSet`을 호출하는 자리가 라운지와 쇼룸까지 여섯 곳이라 인자를 늘리면 전부 손봐야 한다.
