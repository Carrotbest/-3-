## Task 1 — 상단 KPI 그래픽 차트(컴팩트 + 모션)

현재 화면은 `h-[calc(100dvh-7rem)]` 안에서 세로 스크롤 없이 표가 채워진다. **KPI 밴드는 컴팩트(높이 ≈6.5~7.5rem)** 로 만들고, 표 영역이 남은 높이를 갖도록 `min-h-0 flex-1`를 유지한다(페이지 세로 스크롤 금지 원칙 유지).

탭 badge와 **중복되지 않는 정보**를 우선한다. 4타일 권장:
1. **상태 분포** — 4상태(입고대기/창고보관/소진완료/폐기) 비율 **스택 바**(Task 2의 탭 컬러와 **동일 색**) + 총 건수. 세그먼트 hover 시 라벨/건수 툴팁.
2. **창고 재고(yds)** — 창고보관 항목의 `보유 yds 합계` 큰 숫자 + `잔량 합계` 보조. 보유 대비 **소진 진행률**(= 출고누계 / 보유합계)을 얇은 진행바 또는 소형 라디얼로.
3. **출고 누계(yds)** — `outboundTotal` 합계 + 출고 건수. (원하면 최근 N건 미니 스파크라인, 공간 없으면 생략)
4. **입고 대기** — READY 건수 + "다음 채번 번호"(현재 최대 R&D No. +1, `maxStorageNumber` 재사용) 안내.

모션 규칙:
- 타일은 `Reveal`로 등장(딜레이 0/75/150/225).
- 숫자는 `NumberTicker`에 **`startOnView`** 적용, `duration={GAUGE_MS}`.
- 바/라디얼 채움은 `useInView` 게이트 + `transition-[width] duration-[1500ms] [transition-timing-function:cubic-bezier(0.65,0,0.35,1)] motion-reduce:transition-none`.
- 값이 바뀌면(입고·출고 등 처리 후) 자연스럽게 재애니메이션되면 좋음(강제 아님).
- 색은 상태 컬러(Task 2)와 통일. 그라데이션 남용 금지(R35에서 히어로 그라데이션 제거 방침 유지) — 평면 색 + 은은한 틴트 정도.

## Task 2 — 탭을 컬러로 명확히 구분

4개 탭에 고정 액센트를 부여한다(기존 `FABRIC_STATUS_META[].tone`과 정합):
- 입고 대기 READY = **amber**, 창고 보관 WAREHOUSE = **emerald**, 소진 완료 EXHAUSTED = **slate**, 폐기 DISPOSED = **rose**.

적용:
- **비활성 탭**: 좌측 점(dot) 또는 얇은 컬러 인디케이터 + 무채색 텍스트.
- **활성 탭**: 해당 컬러 배경(연한 틴트) + 진한 컬러 텍스트 + 하단/좌측 컬러 바. 한눈에 어느 탭인지 구분되게.
- 탭 **badge(건수)** 도 상태 컬러 톤으로.
- 현재 탭 컬러를 **표 컨테이너 상단 보더/헤더 밑줄**에 얇게 반영해 "지금 이 탭" 맥락을 유지.
- 다크/라이트 모두 대비 확보(예: `bg-amber-500/12 text-amber-700 dark:text-amber-300` 류).

## Task 3 — 탭 간 행/열 간격 완전 통일(이질감 제거) ★핵심 버그 수정

**원인**: 지금은 `SELECTABLE_WIDTHS`(체크박스 있는 READY/WAREHOUSE)와 `STANDARD_WIDTHS`(나머지)가 다르고, 체크박스 `<col>`·`<th>`·`<td>`가 조건부로만 렌더되어 **탭 전환 시 열 폭·위치가 밀린다**. 처리 열 폭도 `w-[17%]` vs `w-[12%]`로 다르다.

**수정**:
- 열 너비 배열을 **단일 `COLUMN_WIDTHS` 하나로 통일**하고 `SELECTABLE_WIDTHS`/`STANDARD_WIDTHS` 제거.
- **체크박스 열을 4개 탭 모두 항상 렌더**한다(아래 Task 5에서 모든 탭 선택 허용). 처리 열 폭도 전 탭 동일 값 하나로 고정.
- **행 높이 고정**: 모든 `TableRow`에 동일 높이(예: `h-9`)와 동일 `px/py`를 적용. 셀 내용(아이콘 버튼/텍스트/배지)이 달라도 행 높이가 변하지 않게 `leading` 및 버튼 크기(`size-7`) 고정.
- 빈 상태 행도 동일 열 수(체크 + 코어 + 처리)를 유지해 `colSpan` 계산 일관.
- 결과: 탭을 넘겨도 **열 경계선이 픽셀 단위로 동일**해야 한다.

## Task 4 — 탭 전환 모션

- 표 영역(툴바 아래 컨테이너)에 탭 전환 시 **짧은 크로스페이드 + 살짝 슬라이드**를 준다.
  - 예: 컨테이너에 `key={tab}` 부여 후 mount 시 `opacity-0 translate-y-1` → `opacity-100 translate-y-0`, `duration-200~300 ease-out`.
  - 방향성을 주려면 탭 인덱스 증감에 따라 좌/우(±)로 살짝 슬라이드해도 좋다(과하지 않게 4~8px).
- KPI 밴드는 재애니메이션하지 않아도 됨(값이 바뀌면 숫자만 자연 갱신).
- `motion-reduce:` 에서는 전환 애니메이션 제거.
- 성능: 표 전체 리마운트가 부담되면 wrapper div만 애니메이션.

## Task 5 — 드래그로 여러 행 동시 선택(범위 선택)

현재는 개별 체크박스만 가능. **행 위에서 드래그하면 지나간 행이 연속 선택**되게 한다(앱의 기존 드래그 관용구 — R40 그리드 십자선택·R41 캘린더 기간선택과 동일한 mousedown/mouseenter/window-mouseup 패턴 사용).

- 선택은 **4개 탭 모두 허용**(소진/폐기 탭에서도 선택 후 일괄 복구 가능해야 하므로).
- 동작:
  - 행 본문 `onMouseDown` → 앵커 행 기억, `draggingRef=true`, 해당 행 선택 상태로 초기화(기존 선택은 Shift/Ctrl 없으면 대체).
  - `onMouseEnter`(드래그 중) → 앵커~현재 행 사이 **연속 범위**를 선택으로 설정(rows 배열 인덱스 기준).
  - `window` `mouseup` → `draggingRef=false`로 확정.
  - **행 클릭(=상세 열기)과 충돌 방지**: 드래그로 2개 이상 행을 지났거나 앵커와 다른 행에서 mouseup 되면 그 클릭은 상세를 열지 않는다(`suppressClickRef` 등으로 1회 무시).
  - 액션 버튼/체크박스 셀에서 시작한 mousedown은 범위선택을 시작하지 않음(`stopPropagation` 유지).
- 기존 개별 체크박스·전체선택 체크박스는 그대로 동작.
- 선택된 행은 은은한 틴트 + 좌측 컬러 바(현재 탭 컬러)로 표시.
- 접근성: Shift+↑/↓로 범위 확장(가능하면), 아니면 기존 체크박스 키보드 조작 유지.

## Task 6 — 선택 항목을 탭으로 드래그앤드롭 → 상태 이동

선택된 원단들을 **탭 헤더로 끌어다 놓으면** 해당 상태 전이가 실행된다.

- **드래그 시작점**: 체크박스 열 안(또는 옆)에 작은 **그립 핸들(⠿, `GripVertical`)** 을 두고 이 핸들에만 `draggable`을 준다. (행 본문 mousedown은 Task 5의 범위선택이므로 충돌 방지 — 반드시 분리할 것.)
  - 핸들 드래그 시 **현재 선택 전체**를 끌고 간다(핸들이 속한 행이 선택에 없으면 그 행만).
  - `dragstart`에서 `dataTransfer.setData("text/plain", ...)`, `effectAllowed="move"`, 드래그 이미지에 "N건" 같은 간단 라벨(가능하면).
- **드롭 대상**: 4개 탭 트리거가 드롭존(`onDragOver` preventDefault, `onDrop` 처리).
  - 드래그 중 **유효한 탭만 강조**(컬러 링/배경), 무효 탭은 흐리게 + `cursor: no-drop` 느낌.
- **전이 매트릭스**(드롭 시 **기존 다이얼로그를 그대로 열어** 필요한 입력을 받는다 — 새 로직 만들지 말고 `openAction(kind, items)` 재사용):
  | 출발(선택 행 상태) | 드롭 탭 | 동작 |
  |---|---|---|
  | READY | 창고 보관 | `RECEIVE` 다이얼로그(순차 4자리 채번 + yds 입력) |
  | READY | 폐기 | `DISPOSE` 다이얼로그(사유 선택) |
  | WAREHOUSE | 소진 완료 | `EXHAUST` |
  | WAREHOUSE | 폐기 | `DISPOSE`(사유) |
  | EXHAUSTED / DISPOSED | 창고 보관(또는 입고 대기) | `RESTORE`(기존 복구 로직: 폐기 전 상태가 READY면 READY로) |
  | 그 외 조합(같은 탭 포함) | — | 무시(무효 표시) |
- 선택 행들의 상태가 섞여 있으면, **드롭 탭 기준으로 유효한 항목만** 대상으로 하고 나머지는 제외(툴바/다이얼로그에 "N건만 처리 가능" 안내).
- 드롭 후 처리 완료되면 기존처럼 해당 탭으로 이동하고 선택 해제.
- 키보드/마우스 대체 경로 유지: 기존 툴바 버튼(선택 입고/일괄 폐기)과 행 액션 버튼은 **그대로 둔다**(DnD는 보조 수단).
