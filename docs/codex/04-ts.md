# 작업지시 04 — TS 관리 화면

## 맡을 파일 (이 1개만 새로 만든다)

- `assets/js/views/ts.js`

다른 파일은 **읽기만** 한다. 공용 CSS는 건드리지 마라 — 화면 전용 스타일은
`assets/js/views/development.js`처럼 파일 안 `STYLE_TEXT` 상수에 넣고 `build()`에서 `root`에 붙인다.

## 먼저 읽을 것

1. `assets/js/views/development.js` — 뷰 구조·스타일 주입·상세 패널 패턴의 본보기. **이 형태를 따른다.**
2. `assets/js/ui/widgets.js`, `assets/js/ui/table.js`, `assets/js/ui/chart.js`
3. `assets/js/data/sample.js` 의 `sampleTs()` — 이 화면이 다루는 레코드 형태
4. `assets/js/data/schema.js` 의 `MEMBERS`

## 레코드 형태

```js
{ id:'TS26-018', receivedAt:'2026-07-28', subject:'이색 클레임', from:'사업10부 3팀',
  owner:'김지현', state:'접수'|'처리중'|'완료', orderQty:1840|null, unlinkedReason:'개발 검토 종료'|null }
```

상태는 `store.get().ts` 배열에 있다. 이 화면은 **웹에서 직접 입력하는 화면**이다
(TDS 엑셀과 무관하다). 변경은 `store.set({ ts: 다음배열 })`로 하고,
같은 배열을 그대로 `localStorage['fabric.ts']`에 JSON으로 저장해 새로고침해도 남게 한다.
읽을 때는 저장된 값이 있으면 그걸 쓰고, 없으면 store의 값을 쓴다.

## 만들 것 (IA_화면구성_v7 「TS 관리」 행 기준)

1. **viewHead** — eyebrow `Technical Services`, 제목 `TS 관리`,
   subtitle `접수부터 완료·발주 기여까지 한 흐름으로 기록합니다.`
   actions에 `+ 신규 접수` (primary 버튼)
2. **상태별 집계 KPI 4장** — 접수 / 처리중 / 완료 / 발주 미연결.
   "발주 미연결"은 `state==='완료' && !orderQty` 인 건수이고 0이 아니면 crit 톤.
3. **발주량 기입률** — 완료 건 중 `orderQty`가 있는 비율.
   `progress()`로 현재값을 보여주고 그 아래 `완료 N건 중 M건 기입` 문구.
   이 화면의 존재 이유이므로 눈에 띄게 배치한다.
4. **접수 건 목록** — `createTable`.
   컬럼: TS# / 접수일 / Subject / 요청처 / 담당 / 상태(배지) / 발주량.
   상단에 상태 탭(`.tabs`) — 전체 N / 접수 N / 처리중 N / 완료 N. 탭 전환은 `setFilter`로 한다.
   행 클릭 시 우측 상세 패널을 연다(development.js의 `.detail` 패턴 재사용).
5. **등록 폼 5블록** — 상세 패널 안이 아니라 별도 카드로 만든다.
   `접수 / 출처 / 대상 / 분석 / 결과` 5개 구획을 `.form-grid`와 `.field`로 구성한다.
   - 접수: 접수일 · 접수 경로 · 담당(select, MEMBERS)
   - 출처: 요청처 구분(사업부/협력사/바이어) · 요청처명
   - 대상: Style No. · FL No. · 조직
   - 분석: 유형(select) · 원인 · 시험 항목
   - 결과: 처리 결과 · 완료일 · **발주량** · **발주 미연결 사유**(select)
6. **완료 저장 규칙 — 이 화면의 핵심이다.**
   상태를 `완료`로 저장하려 할 때 `발주량`과 `발주 미연결 사유`가 **둘 다 비어 있으면 저장되지 않는다.**
   - 저장 버튼을 비활성으로 만들지 말고, 눌렀을 때 해당 필드에 오류 메시지를 띄운다
     (`aria-invalid="true"` + 필드 아래 `.field__error` 문구).
   - 문구: `완료로 저장하려면 발주량 또는 발주 미연결 사유 중 하나를 입력해야 합니다.`
   - 발주량을 입력하면 미연결 사유는 비활성이 되고, 반대도 마찬가지다.
7. **유형별 통계** — `createChart`의 가로 막대(`horizontal:true`)로 유형별 건수.
