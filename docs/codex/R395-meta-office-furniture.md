# R395 — META 2단계: 방 이름을 바닥 글자로 바꾸고 가구를 채운다

상태: 미착수. R394가 끝나 화면은 돌아간다. 지금은 책상과 모니터만 있어 사무실로 안 보이고, 방 이름표가 화면을 덮는다.

2026-11-06 박향근 지적 두 가지다.

1. "초안이미지랑 너무 다르지 않냐" — 가구가 없어 휑하다.
2. "방 이름들이 너무 크고 구분이 잘 안된다", "방 라벨 테두리나 배경 같은거 없애고 글자만 3D형태로 하고 아바타(라벨포함)와 방 라벨이랑 확실히 구분해줘"

## 대상

`src/components/meta/OfficeScene.tsx` 하나다. 다른 파일은 손대지 마라. 단 `src/index.css`에 색 토큰을 더하는 것은 허용한다(아래 3절).

둘 다 `.codex-runs/` 안이고 gitignore 대상이라 저장소에 커밋되지 않는다.

- `R395-reference-furniture.html` — **네가 전에 만든 것이다.** 가구 함수가 전부 들어 있다: `deskUnit`, `cabinet`, `bookshelf`, `sofaSet`, `coffeeTable`, `meetingTable`, `whiteboard`, `printer`, `waterCooler`, `fabricRack`, `boxStack`, `serverRack`, `swatchStand`, `labBench`, `rug`, `plant`, `floorLamp`, `gallery`, `figure`, 그리고 바닥·벽 텍스처(`woodTex`, `tileTex`, `carpetTex`, `wallTex`, `epoxyTex`, `floorFor`, `outerWall`). **이 코드를 그대로 가져와 TypeScript로 옮겨라.** 새로 짜지 마라.
- `R395-furniture-spec.md` — 가구 치수와 방 유형별 배치 표다. 위 참고 파일과 어긋나면 **참고 파일의 실제 코드를 따른다.** 그쪽이 이미 돌아가 본 것이다.

**가져오지 말 것**: `buildMemberSeat`, `memberRow`, `showMember`, 담당자 집계 막대. 2026-11-06 박향근 지시로 아바타를 팀으로 묶지 않는다. 사람 단위는 `presence` 한 줄이다.

## 1. 방 이름 — 바닥에 눕힌 글자로 바꾼다

지금은 흰 알약에 굵은 검정 글자이고 공중에 떠서 카메라를 따라 돈다. 그래서 크고, 서로 겹치고, 아바타 이름표와 똑같이 생겼다.

**바닥에 눕힌 글자로 바꾼다.** 실제 공간에 속한 글자가 되어 겹치지 않고, 아바타 이름표와 형태가 완전히 달라진다.

### 그리는 법

- 캔버스에 **글자만** 그린다. 배경을 칠하지 마라. 테두리를 긋지 마라. `clearRect`로 투명하게 두고 `fillText`만 한다.
- 글자색은 그 방의 **구역 색**(`theme.zones[room.zone]`)이다. 흰색이나 검정으로 하지 마라. 구역이 색으로 읽혀야 한다.
- 굵기 700, 대문자 그대로, `letterSpacing`을 글자 크기의 0.06배 준다. 방 이름은 전부 영문 대문자라 자간이 있어야 읽힌다.
- 캔버스 크기는 글자에 딱 맞춘다(좌우 여백 글자 크기의 0.2배).

### 놓는 법

- `PlaneGeometry`에 입혀 `rotation.x = -Math.PI / 2`로 **눕힌다.** `Sprite`를 쓰지 마라. 카메라를 따라 돌면 안 된다.
- 위치는 방 **앞쪽 빈 바닥**이다. 방 로컬 좌표로 `(0, 0.04, room.d / 2 - 0.75)`. 가구는 방 뒤쪽에 서므로 앞쪽은 비어 있다.
- 크기는 방 폭에 맞춘다. 평면의 가로를 `room.w * 0.66`으로 하고 세로는 캔버스 비율 그대로다. 방이 좁든 넓든 글자가 방 안에 들어간다.
- `depthWrite = false`, `transparent = true`, `renderOrder = 2`. 바닥 카펫 위에 얹힌다.
- `material`은 `MeshBasicMaterial`이다. 조명을 받으면 어두워진다.

### 두께를 준다

박향근이 "3D형태"라고 한 것이다. 같은 글자 평면을 **한 겹 더** 깐다.

- 아래 겹: `y = 0.035`, 색은 글자색을 검정과 0.55로 섞은 값, `opacity 0.5`.
- 위 겹: `y = 0.045`, 원래 색.
- 두 겹의 x를 `0.04` 어긋나게 하고 z도 `0.04` 어긋나게 한다. 비스듬히 밀려 나온 그림자가 생겨 글자가 바닥에서 떠 보인다.

### 클릭

지금 방 핀이 클릭 대상(`pickables`)에 들어 있다. 바닥 글자도 그대로 클릭 대상으로 두되, 방 전체를 덮는 투명 클릭 판이 이미 있으므로 **글자를 클릭 대상에서 빼도 된다.** 둘 중 하나만 남겨 중복 히트를 없애라.

## 2. 아바타 이름표 — 작게 줄이고 모양을 가른다

방 이름과 **확실히 달라야 한다.** 방 이름은 바닥에 누운 큰 색 글자, 아바타 이름은 공중에 뜬 작은 알약이다.

- `Sprite`를 그대로 쓴다. 카메라를 향해 돈다. 이건 유지한다.
- **크기를 지금의 절반 아래로 줄인다.** 지금 `scale`이 `0.021 × 0.88`이다. 기본 배율을 `0.0085`로 바꾼다.
- 알약 배경은 남기되 **반투명**으로 한다. 배경 알파 `0.82`, 테두리는 긋지 마라.
- 글자 굵기 600, 크기는 캔버스 기준 30(지금 34).
- 왼쪽 세로 색 막대를 없애고 **글자 앞에 지름 8px 원점** 하나를 그 사람 색으로 찍는다.
- 적는 내용은 지금처럼 `이름 · 화면`이다. 화면 이름이 길면 앞 10자까지만 적고 `…`을 붙인다.
- 본인(`isSelf`)은 이름 뒤에 ` (나)`를 붙인다.

### 화면에서 일정한 크기로 보이게 한다

지금은 줌을 당기면 이름표도 같이 커진다. 직교 카메라라 `camera.zoom`으로 보정할 수 있다.

매 프레임 아바타 이름표에만 아래를 먹인다. 방 바닥 글자는 **보정하지 마라.** 그건 공간에 속한 글자다.

```
sprite.scale.set(baseW / camera.zoom, baseH / camera.zoom, 1)
```

`baseW`, `baseH`는 라벨을 만들 때 계산한 값을 `sprite.userData`에 넣어 둔다.

## 3. 바닥과 벽

참고 파일의 `woodTex`, `tileTex`, `carpetTex`, `wallTex`, `epoxyTex`, `floorFor`, `outerWall`을 그대로 옮긴다.

텍스처는 **흰 바탕에 명암만** 그리고 색은 `material.color`로 입힌다. 그래야 밝은 모드와 어두운 모드를 한 벌로 처리한다. 테마가 바뀔 때 텍스처를 다시 만들지 마라.

`src/index.css`의 `:root`와 어두운 모드 블록 **양쪽에** 아래를 더한다. 한쪽만 더하면 그 모드에서 색이 없다. R394에서 이미 더한 여섯 개(`--scene-bg`, `--scene-floor`, `--scene-wall`, `--scene-desk`, `--scene-metal`, `--scene-screen`)는 그대로 두고 더한다.

방 벽은 높이 2.6, 두께 0.18로 **북쪽과 서쪽 두 면**에 세운다. 구역 색 띠는 북쪽 벽 윗부분이다. 남쪽과 동쪽은 유리 파티션(높이 1.5, 반투명)이고 남쪽 가운데 폭 1.8을 입구로 비운다.

바깥은 북쪽(z −21)과 서쪽(x −27)에만 높이 3.4 외벽을 세우고 창문 띠를 넣는다. 카메라가 남동쪽에서 보므로 이 두 면은 시야를 가리지 않는다. 남쪽과 동쪽은 높이 0.25 턱만 둔다.

## 5. 사람

참고 파일의 `figure`를 옮긴다. 키 1.7이고 다리, 몸통, 팔, 목, 머리, 머리카락으로 이루어진다.

- 옷과 머리 색은 `uid` 문자열의 문자 코드 합으로 팔레트에서 고른다. **랜덤을 쓰지 마라.** 새로 고칠 때마다 색이 바뀌면 누가 누군지 못 알아본다. R394의 `colorOf` 규칙을 그대로 쓴다.
- 방의 빈 의자부터 채워 **앉은 자세**로 앉힌다. 의자가 다 차면 방 앞쪽에 선다. 앉은 자세와 선 자세는 참고 파일에 둘 다 있다.
- 본인(`isSelf`)의 발밑 이중 고리는 R394에서 넣었다. 그대로 둔다.
- `prefers-reduced-motion`이면 움직임을 끈다.

## 하지 말 것

- 담당자 집계나 팀 묶음을 만들지 마라. 사람 단위는 `presence` 한 줄이다.
- 예시 데이터나 더미 사람을 만들지 마라. 접속자가 없으면 빈 사무실이 맞다.
- `src/data/presence.ts`, `src/routes/Meta.tsx`, `src/components/meta/usePresencePeople.ts`를 고치지 마라.
- 외부 3D 파일, 이미지, 폰트 파일을 불러오지 마라. 전부 코드로 만든다. `TextGeometry`와 `FontLoader`를 쓰지 마라. 폰트 JSON이 필요해진다.
- `@react-three/fiber`나 `drei`를 들이지 마라.
- 갈아치운 코드를 `~Legacy` 같은 이름으로 남기지 마라. 지운다.
- 코드를 한 줄로 눌러 담지 마라. 들여쓰기와 줄바꿈을 지킨다.
- 한글을 영어로 바꾸지 마라. 파일은 UTF-8이다.
- 커밋하거나 푸시하지 마라.

## 성능과 정리

- 지오메트리와 재질을 공유한다. 메시가 2000개를 넘으면 소품부터 줄인다.
- 그림자는 벽, 책상, 큰 가구, 사람까지다. 소품(키보드, 머그, 서류, 책, LED, 조명 패널)은 `castShadow = false`.
- 컴포넌트가 사라질 때 만든 geometry, material, texture를 모두 `dispose()` 한다. 새로 만든 텍스처가 많아지므로 **빠뜨리면 화면을 오갈 때마다 GPU 메모리가 샌다.**
