## 1. 깃발을 육각 기둥으로 바꾼다

지금 `roomFlag`(약 530행)가 **평면 한 장**이다. 카메라를 돌리면 옆에서 보여 글자가 납작해지고, 깃발 끝 V자 홈 때문에 글자 뒤가 잘린다.

**평면을 지우고 육각 기둥으로 바꾼다.**

### 모양

- `new THREE.CylinderGeometry(1.05, 1.05, 0.92, 6, 1, true)`다. 옆면만 쓰고 위아래는 뚫는다(`openEnded = true`).
- 기둥 자리는 지금과 같다. 로컬 `(-room.w / 2 + 1.4, 0, -room.d / 2 + 1.4)`다.
- 육각 기둥의 `y`는 **3.9**다. 지지 기둥은 지금처럼 높이 4.4, 굵기 0.06, 그 방 `ROOM_ACCENT` 색이다.
- 위아래 마감 테두리를 둘 더한다. `CylinderGeometry(1.1, 1.1, 0.06, 6)`를 `y = 4.39`와 `y = 3.41`에 둔다. 재질은 그 방 accent다.
- 받침은 지금 그대로다.

### 글자

- 캔버스는 **1536 × 256**이다. 가로를 여섯으로 나눠 **한 칸에 방 이름을 한 번씩, 모두 여섯 번** 그린다. 한 칸이 256 × 256이다.
- 원기둥 UV가 둘레를 0에서 1로 감으므로 한 면에 이름이 하나씩 온다. **어느 각도에서 보든 정면에 이름이 있다.** 이것이 이번 지시의 핵심이다.
- 칸마다 바탕은 그 방 `ROOM_ACCENT`, 글자는 흰색 볼드다. 칸 경계에 폭 4짜리 흰 세로선을 그어 면을 가른다.
- 글자 크기는 **54px에서 시작하고 이름이 칸에 안 들어가면 줄인다.** `measureText`로 재서 폭이 228을 넘으면 4씩 줄인다. 36px 아래로는 내리지 말고 거기서 멈춘다. `TECHNICAL REFERENCES`가 가장 긴 이름이다.
- 긴 이름은 **두 줄로 접는다.** 공백에서 끊어 위아래로 그린다. 그래야 글자가 안 작아진다. 두 줄일 때 글자 크기는 44px이다.
- `destination-out`으로 홈을 파지 마라. 육각 기둥에는 V자 홈이 없다.

### 지울 것

- 평면 `banner`와 그 재질.
- 바닥 그림자 판(`shade`)은 **남긴다.** 다만 크기를 `3.2 × 1`에서 **`2.2 × 2.2`**로 바꾸고 자리를 기둥 바로 아래 `(0, 0.032, 0)`로 옮긴다. 육각 기둥이 기둥 위에 올라앉으므로 그림자도 가운데다.

## 2. 섹션 간판을 키우고 네온을 세게 한다

| 뒤판 세로 | 1.2 | **1.9** |

## 3. 곡선을 더한다

전체를 부드럽게 만든다. **모서리를 둥글리는 것이지 모양을 바꾸는 것이 아니다.**

### 벽

- **섹션 격벽 토막의 양 끝**에 반지름 0.1 세로 원기둥을 벽 높이(2.2)로 세운다. 지금 구멍 가장자리에만 기둥이 있고 토막 끝에는 없다.
- **파티션 끝을 전부 둥글게 한다.** `partition`의 `rounded` 인자가 기본 `false`다. **호출 전부에서 `true`로 바꾼다.**
- **외벽 창틀 기둥의 모서리**는 그대로 둔다. 창은 각진 것이 맞다.

### 가구

아래 함수에 둥근 마감을 더한다. 치수는 바꾸지 마라.

| 함수 | 무엇을 |
|---|---|
| `buildDesk` | 상판 앞쪽 긴 변에 반지름 0.05 원기둥을 상판 길이만큼 눕혀 붙인다 |
| `cabinet` | 윗면 앞 모서리에 같은 방식으로 반지름 0.04 원기둥 |
| `bookshelf` | 좌우 기둥을 상자에서 반지름 0.05 원기둥으로 바꾼다 |
| `benchRow` | 상판 앞 긴 변에 반지름 0.05 원기둥 |
| `shelfDivider` | 좌우 기둥을 반지름 0.055 원기둥으로 바꾼다 |
| `meetingTable` | 이미 원형이다. 그대로 |
| `sofaSet`, `armchair` | 등판 윗면에 반지름 0.09 원기둥을 눕혀 붙인다 |
| `whiteboard` | 네 모서리에 반지름 0.03 원기둥 |

원기둥을 눕힐 때는 `rotation.z = Math.PI / 2`(가로)나 `rotation.x = Math.PI / 2`(세로)를 쓴다.

**메시가 는다.** 전부 `addInstanced`로 묶을 수는 없으므로 한 함수에 최대 두 개까지만 더한다. 총 메시 상한을 지켜라.

## 4. 오브젝트 팝업 (기능 계획 4단계)

### 클릭되는 오브젝트

`facilities.ts`에 **새 배열**을 더한다. 기존 `META_FACILITIES`는 화면으로 이동하는 링크라 그대로 두고, 이것은 **팝업만 띄우는 오브젝트**다.

```
export interface MetaObject {
  roomPath: string
  id: string
  name: string
  position: [number, number, number]
  hitSize: [number, number, number]
}

export const META_OBJECTS: MetaObject[] = [ ... ]
```

여섯 개다. 자리는 그 방 안에서 실제 가구가 선 좌표에 맞춰라.

| id | 방 | 어느 가구 |
|---|---|---|
| `warehouse-rack` | `/warehouse` | 3팀 랙 줄 가운데 |
| `dd-wall` | `/development/workspace` | 모니터 벽 |
| `request-hanger` | `/request` | 원단 행거 줄 |
| `rdda-screen` | `/rdda` | 대형 스크린 |
| `macro-ticker` | `/trend/macro` | 티커 보드 |
| `calendar-board` | `/calendar` | 월간 보드 |

### 씬 쪽

- 방마다 그 방의 `META_OBJECTS`를 돌며 **보이지 않는 히트박스**를 만든다. `META_FACILITIES`가 하는 방식 그대로다.
- `userData`는 `{ kind: "object", id }`다.
- **방을 고른 상태에서만 보인다.** `selectRoom`이 시설 라벨을 켜고 끄는 자리에 같이 넣어라.
- 누르면 `onPick("object", id)`를 부른다. `onPick`의 `kind`에 `"object"`를 더한다.
- **히트박스 위에 작은 표식**을 띄운다. 반지름 0.18 구를 `y = hitSize[1] + 0.3`에 두고 그 방 accent 색이다. 누를 수 있다는 것이 보여야 한다. 방을 골랐을 때만 보인다.

### 화면 쪽

`Meta.tsx`에서 `onPick`의 `"object"`를 받아 **오른쪽 패널 위에 카드**를 띄운다. 새 모달을 만들지 마라. 닫기 버튼 하나를 둔다.

카드 내용은 `useAppStore`에서 읽는다. **`Meta.tsx`에 `useAppStore`를 import 해도 코드 분리는 안 깨진다.** 스토어는 이미 메인 번들에 있다. three.js만 따로 서 있으면 된다.

| id | 보여 줄 것 | 어디서 |
|---|---|---|
| `warehouse-rack` | 창고보관 건수, 잔량 합계, 최근 입고 3건 | `fabric-ledger.ts`의 `buildFabricLedger` |
| `dd-wall` | 진행 중 건수, 지연 건수, 이번 주 완료 | `derive.ts`의 `isInProgress`와 `isScheduleOpen` |
| `request-hanger` | 전체 스타일 수, 미연결 옵션 수 | 저장 키 `requests` |
| `rdda-screen` | 최근 집계 세 줄 | 저장 키 `rdda`. 없으면 "집계 없음" |
| `macro-ticker` | 최근 지표 세 줄 | `public/data/trend/kpi.json`을 **읽지 마라.** 이미 스토어에 올라온 값만 쓴다. 없으면 "수집 전" |
| `calendar-board` | 이번 주 일정 세 건 | 저장 키 `events` |

**값이 없으면 숫자를 지어내지 마라.** "집계 없음", "수집 전"처럼 적어라.

## 5. 1, 2단계 보완

새로 만들지 말고 아래만 고친다.

- **말풍선이 이름표와 겹친다.** 말풍선 `y`를 2.5에서 **2.95**로 올린다.
- **채팅 목록이 새 메시지로 안 내려간다.** 목록 `div`에 `ref`를 걸고 메시지가 늘면 `scrollTop = scrollHeight`로 내린다.
- **걷다가 방을 옮기면 옛 목적지가 남는다.** `presence.path`가 바뀌면 `Meta.tsx`의 `spot` 상태를 `undefined`로 비워라.
- **채팅 입력에 포커스가 있을 때 Esc가 방 선택을 풀면 안 된다.** `OfficeScene`의 `handleKeyDown`에서 `document.activeElement`가 `input`이면 건너뛴다.

## 성능

곡선 마감과 히트박스가 는다. 평면 깃발 17개가 육각 기둥 17개로 바뀐다. **총 메시 3,500개 이하**를 지킨다. 작업 전이 1,410개다.

육각 기둥 캔버스는 방마다 하나씩 열일곱 장이다. 그대로 둬도 된다. 한 장이 1536 × 256이다.

만든 geometry, material, texture는 정리 단계에서 전부 `dispose()` 해라.

## 실제 적용 결과 (2026-11-09)

**코덱스가 시작도 못 하고 한도에 걸렸다.** 오후 1시 59분에 풀린다던 한도가 2시 넘어서도 그대로였고, 에러 문구가 같은 시각을 다시 가리켰다. 파일은 하나도 안 바뀌었고 보고 파일도 안 생겼다. 박향근 판단으로 클로드가 시공했다.

### 지시서에서 달라진 것

- **육각 기둥을 `FrontSide`로 그렸다.** 지시서에 면 설정을 안 적었는데 `DoubleSide`면 안쪽 면의 글자가 뒤집혀 비친다. `openEnded`에 `FrontSide`면 보이는 세 면만 정상으로 그려진다.
- **글자 접기 기준을 두 단계로 했다.** 한 줄로 54px에서 36px까지 줄여 보고 그래도 228을 넘으면 공백에서 두 줄로 접은 뒤 46px에서 28px까지 다시 줄인다. 지시서는 두 줄일 때 44px 고정이었는데 그러면 긴 이름이 또 넘친다.
- **곡선은 `roundEdge` 보조 함수 하나로 통일했다.** 가구마다 원기둥을 따로 눕히면 코드가 흩어진다. 책상 상판 앞변, 캐비닛 윗면 앞변, 벤치 상판 앞변, 소파와 1인 소파 등판 윗면, 화이트보드 위아래에 썼다. 책장과 책장형 칸막이의 좌우 기둥은 상자를 원기둥으로 바꿨다.
- **오브젝트 팝업 내용을 줄였다.** 지시서는 `buildFabricLedger`와 `isScheduleOpen`까지 쓰라고 했는데, 그 함수들이 인자를 여럿 받아 `Meta.tsx`에서 바로 부르기 어렵다. 스토어에서 바로 읽히는 값으로 한정했다. **없는 값은 "집계 없음", "수집 전"으로 적는다.** 숫자를 지어내지 않았다.

### 알아 둘 것

**내 아바타는 내가 있는 방 안에서만 걷는다.** `spot.path`가 `presence.path`와 같을 때만 목적지가 먹는다. `/meta`를 보는 동안 내 `presence.path`는 `/meta`라서, META 방 바닥을 클릭할 때만 내 아바타가 움직인다. 다른 방 바닥을 클릭하면 아무 일도 안 일어난다. 아바타가 있는 자리는 그 사람이 보고 있는 화면이라는 약속 때문이고, 바꾸려면 그 약속부터 뒤집어야 한다.
