# R54 — PORTFOLIO 시각 재설계: 기능 아이콘·컬러 체계 · 설계/진행/완료 · 대시보드 그래프 · 모션

대상(쓰기): `src/routes/Portfolio.tsx`, `src/data/chemical.ts`(상태 정규화·집계 보강), `src/index.css`(상태·기능 색 토큰), 필요 시 `src/components/portfolio/*`.
무변경: `src/routes/Home.tsx` 호출부, `PortfolioForm.tsx`의 저장 로직, `portfolio-store.ts` 어댑터 인터페이스.

## 배경 (사용자 피드백)
현재 PORTFOLIO 화면은 데이터는 잘 들어왔으나 시각 설계가 약하다. 사용자 요구:
1. 원본 HTML을 참고해 **기능별 아이콘·컬러 조합, 영문 제목 + 한글 설명** 체계를 전반적으로 정비.
2. **카테고리 분류를 시각적으로 명확히 이미지화**.
3. 카테고리별 현황을 **설계 / 진행 / 완료** 3단계로 구분.
4. **카드 클릭 시 아래로 펼쳐지는 확장 영역이 눈에 들어오지 않는다** → 없앤다.
5. **대시보드와 카테고리별 아이템 수치를 이미지·그래프로** 표현.
6. **동적 모션효과** 포함.
7. 아이템 클릭 시 **팝업(모달)은 만족** → 유지·강화.
8. **맨 하단 카테고리 커버리지 섹션은 아예 삭제.**

---

## Task 1 — 상태 체계를 설계 / 진행 / 완료 로 재정의
원본 엑셀 상태값(`미착수`·`개발중`·`개발완료`·`Drop`)을 화면 표기 3단계로 매핑한다.

| 원본 | 화면 표기 | 색(라이트) | 색(다크) |
|---|---|---|---|
| 미착수 | **설계** | `#8a8a8a` | `#9c9c9f` |
| 개발중 | **진행** | `#274754` | `#5b93a3` |
| 개발완료 | **완료** | `#2a9d90` | `#3fb6a7` |
| Drop | **중단**(별도) | `#ef4444` | `#f27272` |

- 이 색들은 **첨부 원본 HTML의 `--status-*` 값 그대로**다. `index.css`에 `--stage-plan / --stage-progress / --stage-done / --stage-drop`으로 라이트·다크 정의(다크 셀렉터는 `.dark`).
- `chemical.ts`에 매핑 헬퍼 추가(`stageOf(state): "plan"|"progress"|"done"|"drop"`). 원본 상태 문자열은 보존하되 화면·집계는 stage 기준.
- **Drop은 진행률 막대에서 제외**하고 별도 배지로만 표기(완료율 왜곡 방지). 카테고리 진행바는 설계/진행/완료 3구간 비율.

## Task 2 — 기능별 아이콘 · 컬러 체계 (14개)
원본 HTML에는 기능별 아이콘·컬러가 없다(중립 팔레트 + 상태색만). 따라서 **기능 아이콘·색을 새로 정의**하되, HTML의 절제된 톤(과채도 금지)을 따른다. `lucide-react`(이미 의존성) 아이콘만 사용.

`chemical.ts` 또는 `Portfolio.tsx`에 매핑 테이블을 둔다. 카테고리명은 원본 그대로 오되, **영문명 매칭 키워드**로 판정(대소문자 무시, 부분일치). 미매칭은 기본값(`Sparkles`, slate).

| 기능(영문 키워드) | 한글 | 아이콘 | 색조 |
|---|---|---|---|
| Cooling | 냉감 | `Snowflake` | sky/cyan |
| Anti-bacterial / Anti-Odor | 항균·항취 | `ShieldCheck` | teal |
| Heat Generation / Warmth | 발열·보온 | `Flame` | orange |
| Thermal Regulation | 온도 조절 | `Thermometer` | amber |
| Moisture / Sweat | 땀 관리 | `Droplets` | blue |
| Durable Press / Shape | 형태안정 | `Shirt` | indigo |
| Anti-Pilling | 필링 방지 | `CircleDashed` | slate |
| Soft Touch / Hand-feel | 촉감 | `Feather` | rose |
| Durability / Workwear | 내구성 | `HardHat` | stone |
| Stretch / Recovery | 신축·복원 | `Move` (또는 `Expand`) | violet |
| Sustainability / Microplastic | 친환경 | `Leaf` | green |
| Recovery / Restorative | 회복 | `Moon` | purple |
| Skin Care / Microbiome | 마이크로바이옴 | `Sparkles` | pink |
| DWR / Water Repellency | 발수 | `Umbrella` | cyan |

- 각 기능색은 **아이콘 배지 배경(옅은 틴트) + 아이콘 색 + 카테고리 강조선**에만 쓴다. 카드 본문은 흰색 유지(현재 톤 유지).
- **영문 제목(크게) + 한글 설명(작게)** 2단 표기를 카테고리·헤더 전반에 일관 적용(원본 HTML 방식 인용).

## Task 3 — 상단 대시보드 (그래프·이미지화) ★
현재 KPI 숫자 나열을 **시각 대시보드**로 교체한다. 좌우 2블록 구성 권장.

**① 전체 요약(좌)** — 4개 지표 유지하되 그래픽 동반:
- **전체 개발 건수**(큰 숫자) + 그 아래 **설계/진행/완료 3구간 스택 바**(Task 1 색), 각 구간 건수·비율 라벨.
- **완료율** 도넛 또는 반원 게이지(완료 ÷ (전체−중단)).
- **검증 통과(PASS)** 건수 + 아이콘.
- **연결 원단(FL)** 고유 수.

**② 카테고리별 아이템 수치(우)** — **가로 막대 차트**:
- 14개 기능을 건수 내림차순으로, 각 막대는 **설계/진행/완료 스택**(3색).
- 막대 왼쪽에 **기능 아이콘 배지 + 영문명/한글명**.
- 막대 hover 시 툴팁(기능명 · 설계 n · 진행 n · 완료 n · 합계).
- 막대 클릭 시 해당 카테고리 선택(아래 목록 이동/필터).
- recharts를 써도 되고 순수 CSS 막대도 무방하나, **앱의 기존 차트 톤**(점선 그리드·절제된 색)과 어긋나지 않게.

## Task 4 — 카테고리 내비 & 목록 (이미지화)
- 좌측 카테고리 레일(현재 구조 유지)에서 각 항목에 **기능 아이콘 배지(색 틴트)** + 영문명 + 한글명 + 건수. 선택 항목은 좌측 컬러 바 + 배경 틴트로 **명확히 강조**.
- 선택된 카테고리 헤더: 큰 아이콘 + 영문명 + 한글명 + 전체 건수 + **설계/진행/완료 스택 바**(현재 있는 바를 3단계로 교체).
- 전략 문구(`적용 대상 및 이유`) 블록은 유지하되 기능색 좌측 보더로 강조.

## Task 5 — 카드: 인라인 확장 제거 → 모달 일원화 ★
- **카드의 아래로 펼쳐지는 확장(chevron) 기능을 완전히 제거**한다(사용자: 눈에 안 들어옴).
- 카드 전체가 클릭 가능 → **바로 상세 모달**(현재 모달은 만족하므로 유지). 카드에 hover 시 살짝 부양 + 커서 포인터.
- 카드 표면 정보 정리: 상단 **상태 배지(설계/진행/완료/중단)** + 분류 태그(Chemical Tech·Yarn Tech 등 원본 태그 유지) + 제목(영문) + 브랜드(작게) + 설명 2~3줄 clamp + 하단에 **FL 개수 칩**·PASS 배지.
- 카드 좌측 또는 상단에 **기능색 얇은 액센트 바**(카테고리 소속 시각화).

## Task 6 — 동적 모션
앱 기존 관례 재사용(새 패키지 금지):
- 카테고리 전환·카드 그리드: `Reveal` stagger(인덱스별 지연 40~60ms).
- KPI 숫자: `NumberTicker startOnView`.
- 스택 바·도넛·가로 막대: `useInView` 게이트 + `transition-[width]/stroke-dashoffset` 800~1200ms `cubic-bezier(.4,0,.2,1)`.
- 카테고리 선택 시 우측 콘텐츠 **짧은 크로스페이드**(`key={category}` + opacity/translate 200~300ms).
- 카드 hover: `hoverLift` 재사용.
- **`prefers-reduced-motion` 시 전부 정지하되 콘텐츠는 정적으로 보일 것**(빈 화면 금지 — 이전 스트림 사고 반복 금지).

## Task 7 — 하단 커버리지 삭제
- 화면 맨 아래 **카테고리 커버리지 섹션을 완전히 삭제**한다(Task 3의 가로 막대가 그 역할을 대체).

## 금지사항
- 새 npm 패키지 금지(lucide-react·recharts·기존 shadcn만). 
- `portfolio-store.ts` 어댑터 인터페이스 변경 금지(Firebase 전환 대비). `PortfolioForm` 저장 로직 변경 금지.
- 실데이터(협력사·브랜드·FL) 저장소 커밋 금지 — 데모는 익명 유지.
- 인라인 확장 부활 금지. `prefers-reduced-motion` 미대응 금지. 커밋 금지.

## 검증(구현 후 자기점검)
1. `tsc --noEmit && vite build` 통과.
2. `#/trend/portfolio`: 상단에 요약 지표 + **카테고리별 가로 막대(설계/진행/완료 스택)** 대시보드가 보인다.
3. 좌측 레일·헤더·카드에 **기능별 아이콘과 색**이 적용되고, 영문명 + 한글명이 함께 표기된다.
4. 카테고리 진행바가 **설계/진행/완료 3구간**이고 Drop은 별도 배지다.
5. 카드 클릭 시 **인라인 확장 없이 바로 모달**이 열린다(chevron 사라짐).
6. **하단 카테고리 커버리지 섹션이 없다.**
7. 진입·전환 모션이 동작하고, `prefers-reduced-motion`에서는 정지하되 내용은 보인다.
