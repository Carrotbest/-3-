# R39 — DD MASTER(전체 현황 시트) 상단 chrome 최소화

목표: `/development/workspace` = `src/routes/DevelopmentMasterSheet.tsx`의 그리드 **위쪽 헤더/툴바가 세로 공간을 너무 많이 차지**한다. 불필요한 요소를 제거하고 나머지를 압축해 **엑셀형 전체 그리드가 더 넓게** 보이도록 한다. 기능은 유지.

대상 파일: `src/routes/DevelopmentMasterSheet.tsx` (return 시작 ~600행의 상단 3개 블록).

## 현재 상단 구성(그리드 위)
전역 Topbar가 이미 "DD MASTER" 제목 + 부제를 표시함(별개, 유지). 컴포넌트 자체 상단은:
- **A행(601~611)**: `TableProperties` 아이콘 + `DD MASTER SHEET` 제목 + `살아있는 현황판` 뱃지 + **설명 문단**("셀을 더블클릭해 즉시 수정… 담당 칸의 아이콘으로 전체 항목 편집") + 우측 액션버튼들(신규 작지 접수 / 핵심 보기 / 공정·결과 / 전체 64열 / 열 너비 초기화).
- **B행(613~618)**: 열 그룹 토글 칩(`GROUPS`) + 상태 범례(완료/진행중/HOLD).
- **C행(620~627)**: 검색 인풋 + 담당 Select + Status Select + 초기화 + 행수(`filtered/scoped`).

## 변경 지시

### 1. A행의 제목·뱃지·설명 블록 제거(중복·장황)
- `TableProperties` 아이콘, `<h2>DD MASTER SHEET</h2>`, `살아있는 현황판` `Badge`, 그리고 **"셀을 더블클릭해…" 설명 `<p>` 전체를 삭제**한다. (전역 Topbar가 이미 "DD MASTER" 제목/부제를 제공하므로 중복이고, 설명은 상시 노출이 불필요.)
- 편집 방법 힌트를 완전히 없애기가 아쉬우면, 액션버튼 옆에 작은 **info 아이콘 + tooltip**(hover 시 "셀 더블클릭 수정 · 담당 칸 ⤢ 아이콘으로 전체 편집")로 **한 곳에 접어** 둘 수 있다(선택, 높이 차지 금지).

### 2. 남은 컨트롤을 2행으로 압축
그리드 위를 **최대 2행**으로 정리한다(현재 3행 → 2행). 권장 배치:
- **1행(툴바)**: 열 그룹 토글 칩(B행)을 왼쪽에 두고, **오른쪽 끝에 액션버튼들**(신규 작지 접수 | 핵심 보기 · 공정·결과 · 전체 64열 · 열 너비 초기화)을 붙인다. 좁은 폭에서는 자연스럽게 wrap 허용.
- **2행(필터)**: 검색 + 담당 + Status + 초기화 + 행수(C행) 유지. 상태 범례(완료/진행중/HOLD)는 이 행의 오른쪽(행수 근처)이나 1행 칩 옆 등 **한 줄 안에 흡수**해 별도 높이를 만들지 않는다.
- 정확한 좌우 배치는 Codex 재량이나 **총 2행 이내**, 모든 기존 기능(프리셋·신규접수·그룹토글·필터·초기화·범례·행수)은 유지.

### 3. 여백·밀도 축소
- 상단 래퍼의 세로 간격을 줄인다: 최상위 `gap-3` → `gap-2`, 툴바/필터 블록의 `p-3` → `p-2`(또는 `py-2`), 칩 `py-1.5` → `py-1` 등 과하지 않게 소폭 축소.
- 그리드 컨테이너(`border-y … flex-1 overflow-auto`)와 하단 레이아웃은 그대로. 압축으로 확보된 높이가 그리드로 가도록 `min-h-0 flex-1` 흐름 유지.
