상태: 미착수. **R407이 끝난 뒤에 한다.**

2026-11-09 박향근 지시 다섯이다.

1. "전체 오피스 톤은 약간 어둡게 첨부한 농도로 맞춰주고"
2. "특정 룸을 클릭 했을 때 확대되면서 룸의 조명이 들어와서 밝게 보이게 하면 어떨까."
3. "아바타들도 좀 더 실제 사람처럼(최소 레고 인형) 좀 크게 만들어주고"

5. "아바타들의 스타일은 모두 다르게 해줘."

6번은 "나중에 각 사용자의 설정에서 아바타를 직접 꾸미게 하고 싶다(이건 생각만해봄)"였다. **이번 범위가 아니다. 설정 화면을 건드리지 마라.**

## R407의 집중 보기를 뒤집는다

**R407 3절은 고른 방만 남기고 나머지를 `visible = false`로 숨기게 했다. 그 조항은 폐기다.**

4번 지시가 "아바타가 보고 있는 룸은 불이 켜져 있게"다. 그러려면 고르지 않은 방도 **보여야** 한다. 숨기면 불을 켤 대상이 없다.

바뀐 규칙이다.

| 상태 | 어떻게 |
|---|---|
| 고른 방 | 불을 켠다. 가장 밝다 |
| 사람이 있는 방 | 불을 켠다 |
| 나머지 | 보이되 어둡다. 숨기지 않는다 |

공용 구역, 섹션 격벽, 섹션 간판, 통로 화분도 숨기지 마라. R407이 만든 `sceneDecor` 그룹은 남겨 두되 `visible`을 끄지 말고 **어둡게만** 한다.

## 대상

`src/components/meta/OfficeScene.tsx`와 `src/index.css`다. `Meta.tsx`, `facilities.ts`, `presence.ts`, `meta-chat.ts`, `usePresencePeople.ts`는 건드리지 마라.

## 1. 기본 톤을 낮춘다

받은 화면은 지금보다 뚜렷하게 어둡고 푸르다. 바닥이 흰색이 아니라 중간 회청색이다.

`src/index.css`의 **밝은 모드만** 고친다.

| 토큰 | 지금 | 바꿀 값 |
|---|---|---|
| `--scene-bg` | `#f4f6fa` | `#e7ebf1` |
| `--scene-floor` | `#f7f9fc` | `#c6cedb` |
| `--scene-wall` | `#e8edf4` | `#d6dde7` |
| `--scene-tile` | `#edf0f5` | `#cdd4df` |

조명도 함께 내린다. **조명만 내리고 토큰을 그대로 두면 안 된다.** 흰 바닥이 회색으로 보일 뿐 색이 탁해진다.

| 자리 | 지금 | 바꿀 값 |
|---|---|---|
| `hemi` 밝은 모드 세기 | 1.1 | **0.72** |
| `hemi.groundColor` 밝은 모드 | `0xdde3ec` | `0xaeb8c6` |
| `sun` 밝은 모드 세기 | 1.15 | **0.8** |
| `ambient` 밝은 모드 세기 | 0.48 | **0.3** |

`repaint`의 같은 줄들도 함께 고쳐라. **어두운 모드 값은 손대지 마라.**

## 2. 방 조명

### 켜고 끄는 단위

방마다 조명 한 벌을 만든다. 함수 하나로 켜고 끈다.

```
const setRoomLit = (path: string, lit: boolean) => { ... }
```

### 조명 한 벌의 구성

**진짜 광원을 방마다 두지 마라.** 열일곱 개면 셰이더 한도에 걸리고 느려진다. 아래 셋으로 흉내 낸다.

1. **천장 조명 패널** 둘. 가로 `room.w * 0.5`, 세로 0.08, 두께 1.2, `y = 3.3`이다. 자리는 `z = ±room.d * 0.22`다. 재질은 `MeshBasicMaterial`이고 **꺼지면 `#8b95a4`, 켜지면 `#ffffff`**다.
2. **바닥 빛 웅덩이** 한 장. 방 카펫과 같은 모양(`makeRoomShape`를 크기 `room.w * 0.86`, `room.d * 0.86`으로 다시 부른다), `y = 0.034`, 수평, 흰색, `depthWrite: false`다. **꺼지면 `opacity = 0`, 켜지면 `0.26`**이다.
3. **방 전체 밝기.** 그 방 그룹을 돌며 재질의 `color`를 건드리지 말고, 꺼진 방에만 **어둡게 덮는 판**을 씌운다. 판 하나로 처리하면 재질을 되돌릴 일이 없다. 카펫과 같은 모양에 크기 `room.w`, `room.d`, `y = 2.9`, 수평, 색 `#1a2230`, `depthWrite: false`, **꺼지면 `opacity = 0.22`, 켜지면 `0`**이다.

**재질 색을 직접 바꾸지 마라.** R403에서 `setRoomDimmed`가 `onBeforeRender`로 재질을 만졌는데, 같은 재질을 여러 방이 공유해서 한 방을 어둡게 하면 다른 방까지 어두워진다.

### 진짜 광원은 하나뿐이다

고른 방에만 `PointLight` 하나를 옮겨 쓴다.

- `new THREE.PointLight(0xfff4e0, 0, 26, 1.6)`를 씬에 하나 만든다. 처음 세기는 0이다.
- 방을 고르면 그 방 중심 `y = 3.0`으로 옮기고 세기를 **1.6**으로 올린다.
- 선택을 풀면 세기를 0으로 내린다.
- **그림자를 켜지 마라.** `castShadow`는 `false`다. 해가 이미 그림자를 만든다.

### 언제 켜지나

`syncPeople`과 `selectRoom`이 끝난 뒤 한 번 계산한다.

```
방이 켜짐 = (고른 방이다) 또는 (그 방에 사람이 있다)
```

고른 방이 없으면 사람이 있는 방만 켜진다. 사람이 없으면 다 꺼진 사무실이다. **그것이 맞다.**

창고와 서버실도 같은 규칙이다.

### R407 집중 보기와의 관계

R407이 넣은 `visible = false` 처리를 **지운다.** 대신 위 조명으로 집중을 만든다. 줌은 R407 그대로 둔다.

## 3. 아바타를 키우고 레고풍으로

지금 캡슐 몸통에 구 머리다. 사람으로 안 읽힌다.

### 크기

- 전체를 **1.4배**로 키운다. 지금 머리 꼭대기가 약 1.6이면 2.2쯤이 된다.
- 이름표와 말풍선 `y`도 같은 비율로 올린다. 이름표는 1.9에서 **2.6**, 말풍선은 2.95에서 **3.7**이다.

### 구성

상자와 원기둥으로만 만든다. 레고 인형 비례다.

| 부위 | 모양 | 치수 |
|---|---|---|
| 받침 | 원기둥 | 반지름 0.34, 높이 0.05, `y = 0.025` |
| 다리 | 상자 둘 | 0.17 × 0.52 × 0.2, `x = ±0.11`, `y = 0.31` |
| 허리 | 상자 | 0.44 × 0.1 × 0.26, `y = 0.62` |
| 몸통 | 상자 | 0.5 × 0.56 × 0.3, `y = 0.95` |
| 팔 | 상자 둘 | 0.12 × 0.46 × 0.16, `x = ±0.31`, `y = 0.96` |
| 손 | 원기둥 둘 | 반지름 0.075, 높이 0.1, `y = 0.71` |
| 목 | 원기둥 | 반지름 0.09, 높이 0.08, `y = 1.27` |
| 머리 | 상자 | 0.42 × 0.42 × 0.4, `y = 1.52` |
| 얼굴 눈 | 상자 둘 | 0.06 × 0.08 × 0.02, `x = ±0.1`, `y = 1.56`, `z = 0.205` |

**기존 `body`, `head`, `leftLeg`, `rightLeg` 이름을 그대로 쓴다.** `PersonVisual`의 다른 코드(걷기, 앉기, 흐리게 하기, 깃발)가 그 이름을 본다. `body`는 몸통 상자, `head`는 머리 상자다. 타입이 `Mesh<CapsuleGeometry>`와 `Mesh<SphereGeometry>`로 박혀 있으면 `Mesh<BoxGeometry>`로 고쳐라.

앉기(`posePerson`)는 다리 회전 그대로 쓰면 된다. 받침은 앉을 때 숨겨라(`visible = false`).

### 스타일을 다르게

`uid`를 숫자로 접어(문자 코드 합) 아래를 고른다. **랜덤을 쓰지 마라.**

| 갈래 | 가짓수 | 값 |
|---|---|---|
| 머리 모양 | 4 | 민머리, 짧은 머리(상자 0.44 × 0.12 × 0.42, `y = 1.73`), 단발(그 위에 0.46 × 0.2 × 0.1을 뒤통수에), 모자(챙 0.5 × 0.05 × 0.34를 앞으로 0.12) |
| 상의 색 | 6 | `#4a6fb5`, `#3d8f86`, `#b5664a`, `#9a5aa8`, `#c4566b`, `#5c6878` |
| 하의 색 | 3 | `#3a4452`, `#4a5668`, `#2f3844` |
| 안경 | 2 | 없음, 있음(상자 0.3 × 0.03 × 0.02를 `y = 1.56`, `z = 0.21`) |

**머리와 손은 피부색 하나로 둔다.** `#e8c49a`다. 여섯 명뿐이라 피부색까지 가르면 어지럽다.

**기존 `person.color`는 받침과 깃발에 쓴다.** 이름표 색과 맞아야 목록에서 찾기 쉽다.

## 하지 말 것

- 방마다 진짜 광원을 두지 마라. 고른 방 하나뿐이다.
- 재질 `color`를 직접 바꿔 방을 어둡게 하지 마라. 재질을 여러 방이 공유한다.
- R407의 육면체 표지, 양면 간판, 꽉 찬 화면, 스페이스 이동, 가구 다리를 되돌리지 마라.
- 설정 화면에 아바타 꾸미기를 만들지 마라. 이번 범위가 아니다.
- 채팅, 말풍선, 상태와 기분, 클릭 이동을 다시 만들지 마라.
- 방 좌표, `w`, `d`, `shape`, 외곽, 통로, 격벽, 가구 치수, 카메라 각도를 바꾸지 마라.
- 어두운 모드 색 토큰을 바꾸지 마라.
- 광륜(`AdditiveBlending`)을 만들지 마라. 천장을 만들지 마라. 후처리를 쓰지 마라.
- 담당자 집계나 팀 묶음을 만들지 마라. 예시 사람을 만들지 마라.
- 랜덤을 쓰지 마라. 아바타 스타일은 `uid` 해시로 정한다.
- 외부 3D 파일, 이미지, 폰트를 불러오지 마라.
- 한글을 영어로 바꾸지 마라. 파일은 UTF-8이다.
- 코드를 한 줄로 눌러 담지 마라. 커밋하거나 푸시하지 마라.
- **함수를 쓰는 자리보다 정의하는 자리가 먼저 와야 한다.** 이 파일에서 이미 세 번 터졌다.

## 성능

방마다 조명 넉 장(패널 둘, 빛 웅덩이, 덮개)이 는다. 열일곱 방이면 68개다. 아바타 한 명이 메시 열둘쯤이다.

**총 메시 3,500개 이하**를 지킨다. R407 뒤 숫자를 기준으로 삼아라.

만든 geometry, material, texture는 정리 단계에서 전부 `dispose()` 해라. 빛 웅덩이와 덮개는 `makeRoomShape`로 만든 `ShapeGeometry`라 방마다 새것이다.
