# R427 그 화면의 메모는 전부 자동으로 펼친다

상태: 구현 완료, 빌드 통과, 로컬 화면 확인 완료. 클로드가 직접 시공했다(2026-11-12).

2026-11-12 박향근 요구다.

> 우측하단 버튼을 클릭하야만 팝업이 뜨는데 메모가 있다면 각 페이지에서 모두 자동으로 띄워줘. 위치는 최초로 저장한 사람이 지정한 위치로 하고 각 유저는 본인의 화면에서 보이도록 할거야. 사용자가 계속 보기 싫으면 체크박스로 더 이상 보지 않기를 누르면돼. 홈화면의 카렌다 스케줄러랑 비슷한 개념이다.

## 무엇이 바뀌었나

R420은 `pinned`(중요 표시)가 켜진 메모만 자동으로 펼쳤다. 나머지는 오른쪽 아래 단추를 눌러야 보였다. 이제 **그 경로의 살아 있는 메모를 전부 펼친다.**

판정에서 `memo.pinned &&` 한 조건을 뺀 것이 전부다. 나머지 세 조건은 그대로다.

| 조건 | 그대로 |
|---|---|
| 경로가 같다 | `activeMemos`가 `memo.path === location.pathname`으로 거른다 |
| 만료 전이다 | `memoIsActive(memo, today)` |
| 그만 보기가 아니다 | `hidden[memo.id]` |

## 끄는 길 둘

- **닫기 단추(X)**는 그 화면을 떠날 때까지만이다. `suppressed`가 경로가 바뀌면 비워진다.
- **「이 메모 그만 보기」**는 이 브라우저에서 계속이다. `memo.hidden` localStorage에 남고 Firestore에 올라가지 않는다. 사람마다 다르고 PC마다 다르다. 다시 보려면 오른쪽 아래 단추를 누른다. 그 단추는 그만 보기한 것까지 포함해 전부 펼친다.

위치는 작성자가 끌어 정한 자리 그대로다. 비율(0~1)로 저장되어 해상도가 달라도 화면 안에 든다. 읽는 사람이 옮길 수는 없다. 남의 메모 머리줄은 끌기가 비활성이다.

## 「중요」 체크를 없앴다

자동 펼침이 모든 메모에 걸리므로 `pinned`가 하는 일이 없어졌다. 새 메모 창과 수정 창에서 체크박스를 빼고 `newPinned`, `editPinned` 상태도 지웠다.

**`ScreenMemo.pinned` 필드는 남긴다.** 옛 문서에 값이 들어 있고 타입에서 빼면 읽을 때 어긋난다. 쓰기는 늘 `true`다. 배포 전 화면을 열어 둔 사람이 있어도 같게 보인다.

**이 값을 다시 읽어 분기하지 말 것.** 읽는 쪽이 사라졌으니 쓰는 값도 뜻이 없다.

## 겹침

한 경로에 메모가 여럿이면 전부 동시에 뜬다. 자리가 겹칠 수 있다. 자리를 정하는 것은 작성자이므로 겹치면 작성자가 끌어 옮긴다. **자동 배치나 겹침 회피를 넣지 않았다.** 넣으면 작성자가 정한 자리가 아니게 된다.
