# R58 — TS·STUDY 덱 튜닝: 카드 수 증가 · 크기 확대 · 원근 강화 · 스크롤 속도 상향

대상(쓰기): `src/components/cards/MaterialDeck.tsx`(TS·STUDY 덱 전용 값).
**HOME 덱(`CoverflowGallery.tsx`)은 카드 수·크기 변경 금지** — 사용자가 "홈 화면 카드 갯수는 적당"이라고 확인.

## 배경 (사용자 피드백)
자동 넘김은 정상 동작 확인됨(만족). 이어서 TS·STUDY 덱만 다듬는다.
1. **스크롤 속도를 조금 더 올린다.**
2. **카드 크기를 살짝 키운다.**
3. **첨부 레퍼런스 형태의 3D**(좌우 카드 원근감)를 더 강하게 적용.
4. **메인 카테고리(TS·STUDY) 덱에 아직 여백이 많다** → **카드 개수를 늘려** 여백을 덮는다. (좌우로 더 퍼뜨리는 방식이 아님 — 앞서 "너무 와이드하다"고 했으므로 `MATERIAL_DECK_SPREAD`를 크게 키우지 말 것.)

## 현재 값 (참고)
```
MATERIAL_DECK_VISIBLE_CARDS = 7
MATERIAL_DECK_SPREAD        = 0.65
MATERIAL_DECK_ROTATE_MAX    = 42
MATERIAL_DECK_DEPTH_STEP    = 90
COVERFLOW_SCALE_STEP        = 0.10
MIN_V = 1.2 / MAX_V = 9
카드 폭  clamp(200px, 22%, 300px)   무대 높이 min-h-[19rem]
```

---

## Task 1 — 표시 카드 수 증가 (여백 커버)
- `MATERIAL_DECK_VISIBLE_CARDS` **7 → 9**로 늘린다(중앙 1 + 좌우 각 4).
- 항목이 9개 미만이면 있는 만큼만 자연스럽게 표시(현재 로직 유지).
- **HOME은 5장 유지**(`HOME_VISIBLE_CARDS` 변경 금지).
- 카드가 늘어도 중앙 카드가 묻히지 않도록 z-index·크기 위계는 유지.

## Task 2 — 카드 크기 확대
- TS·STUDY 카드 폭 `clamp(200px, 22%, 300px)` → **`clamp(230px, 25%, 340px)`** 수준으로 소폭 확대.
- 무대 높이 `min-h-[19rem]` → 카드가 커진 만큼 **`min-h-[21rem]`** 내외로 조정(잘림 방지). 과하게 키우지 말 것(R50의 "낮고 넓은 띠" 기조 유지).
- HOME 카드 폭·무대 높이는 **그대로**.

## Task 3 — 원근감(3D) 강화 ★ 레퍼런스 기준
첨부 레퍼런스는 중앙 카드가 정면·크고, 좌우로 갈수록 **강하게 기울며 뒤로 물러나** 깊이가 확실히 느껴진다. 현재보다 한 단계 더 강화한다.
- `MATERIAL_DECK_ROTATE_MAX` **42 → 52** (좌우 카드 기울기 강화).
- `MATERIAL_DECK_DEPTH_STEP` **90 → 120** (translateZ 후퇴 폭 확대).
- 무대 `perspective` **820px → 720px** (TS·STUDY 무대에만. HOME은 820px 유지) — 값이 작을수록 원근이 강하다.
- `COVERFLOW_SCALE_STEP`은 **0.10 → 0.08**로 완화(translateZ가 이미 축소 효과를 주므로 scale까지 세게 줄이면 바깥 카드가 과도하게 작아진다).
- 깊이 단계 상한(`Math.min(cappedAbs, 3)`)이 9장 기준에 맞도록 **상한을 4로 조정**해 바깥 카드까지 원근이 이어지게 한다.
- 사이드 카드 **불투명도 0.6 유지**(내용이 보여야 함 — 기존 요구).
- 그림자: 중앙은 진하게, 바깥으로 갈수록 옅게(현재 방식 유지·강화).

## Task 4 — 스크롤 속도 상향
- `MAX_V` **9 → 13** (카드/초, 가장자리 최고 속도).
- `MIN_V` **1.2 → 1.8** (dead zone 직후 최저 속도).
- `DEAD_ZONE`(0.12)·`VELOCITY_LERP`(0.18)는 **유지** — 감속 감성과 중앙 정지 동작을 바꾸지 않기 위함.
- 속도만 올리고 **부드러움(보간)은 유지**한다. 뚝뚝 끊기면 안 된다.
- HOME 덱도 같은 상수를 공유한다면 그대로 둔다(속도 상향은 공통 적용 허용).

## 금지사항
- ★ `MaterialDeck.tsx` rAF 루프의 **`const hitBoundary = dt > 0 && ...` 에서 `dt > 0` 가드 제거·변경 절대 금지**(자동 넘김을 살린 수정, 검증 완료).
- `setInterval` 한 칸 이동 방식 부활 금지. 배경 그라데이션·중앙 넘버링 부활 금지.
- **HOME 덱 카드 수(5)·카드 폭·무대 높이 변경 금지.**
- `MATERIAL_DECK_SPREAD`를 크게 키워 좌우로 퍼뜨리지 말 것(여백은 카드 수로 덮는다). 필요 시 0.65~0.72 범위 내 미세 조정만 허용.
- 새 npm 패키지 금지. `TS.tsx`·`Study.tsx`·`Home.tsx` 및 export 시그니처 변경 금지. `prefers-reduced-motion` 유지. 커밋 금지.

## 검증(구현 후 자기점검)
1. `tsc --noEmit && vite build` 통과.
2. `#/study`: 카드가 **9장** 보이고 이전보다 **크며**, 좌우 카드가 **뚜렷하게 기울고 뒤로 물러나** 원근이 느껴진다.
3. 덱 좌우 여백이 이전보다 **줄어들어 꽉 차 보인다**(카드가 과하게 퍼진 느낌은 아니어야 함).
4. 마우스를 가장자리에 두면 **이전보다 빠르게** 넘어가고, 중앙으로 오면 부드럽게 감속·정지한다(끊김 없음).
5. `#/`(HOME) 덱은 **카드 5장·크기 그대로**이며 정상 동작한다.
6. 사이드 카드 내용이 0.6 불투명도로 보인다.
