# R57 — PORTFOLIO 리사이저 확장: 기능 카테고리 좌우 분할 · 상하 분할 · 세로 여유 확대

대상(쓰기): `src/routes/Portfolio.tsx`, 필요 시 리사이저 공통화용 `src/components/portfolio/SplitPane.tsx`(신규).
무변경: `portfolio-store.ts` 어댑터, `PortfolioForm.tsx`, `chemical.ts` 집계, `Home.tsx`.

## 배경 (사용자 피드백)
R56에서 상단(OVERVIEW ↔ CATEGORY MIX) 좌우 스플리터를 넣었고 만족. 이어서:
1. **기능 카테고리 섹션에도 동일한 좌우 조절바** — 좌측 내비(카테고리 레일)와 우측 내용 사이. (현재 카테고리 이름이 `Anti-bacterial / A...`처럼 잘림)
2. **시트 하단이 너무 타이트하다** → 여백을 주고, **기능 카테고리 섹션 전체 세로 크기를 약 1.5배**로 키우면서 위로 좀 올린다.
3. **포트폴리오 상단 섹션과 하단 섹션의 전체 크기도 수동 조절** 가능하게(상하 분할).

---

## Task 0 — 리사이저 공통 컴포넌트로 추출
R56에서 만든 좌우 스플리터 로직을 **재사용 가능한 컴포넌트로 분리**한다(같은 코드를 3번 쓰지 않게).
```tsx
<SplitPane
  orientation="vertical" | "horizontal"   // vertical = 좌우 분할, horizontal = 상하 분할
  storageKey="portfolio-split-top"        // localStorage 키
  defaultRatio={45}                       // %
  min={25} max={75}
  first={<...>} second={<...>}
/>
```
- 드래그 핸들: 두께 6~8px, hover 시 색 강조, `cursor: col-resize`(vertical) / `row-resize`(horizontal).
- 접근성: `role="separator"`, `aria-orientation`, `aria-valuenow/min/max`, **키보드 화살표 조절**(vertical=←→, horizontal=↑↓), 더블클릭 시 `defaultRatio`로 초기화.
- 비율은 `localStorage`에 키별로 저장·복원.
- 모바일(좁은 화면)에서는 핸들 숨기고 세로 스택으로 폴백.
- **R56의 기존 상단 스플리터도 이 컴포넌트로 교체**해 동작·감성을 통일한다(기존 `portfolio-split` 키와 현재 비율은 유지).

## Task 1 — 기능 카테고리 섹션에 좌우 스플리터
- 「기능 카테고리」 섹션 내부: **좌측 카테고리 레일 ↔ 우측 상세/카드 영역** 사이에 `SplitPane orientation="vertical"` 적용.
- `storageKey="portfolio-split-category"`, 기본 비율은 현재 레일 폭에 가깝게(예 22%), 범위 `min=15, max=45`.
- 레일이 넓어지면 **카테고리 영문명이 덜 잘리게** 되어야 한다(`truncate`는 유지하되 폭이 늘면 자연히 더 보임). `title` 툴팁은 계속 유지.
- 레일 내부 스크롤(`overflow-y-auto`)과 카드 영역 스크롤은 각각 독립 유지.

## Task 2 — 상단 ↔ 하단 섹션 상하 스플리터
- 페이지를 **상단 블록**(OVERVIEW + CATEGORY MIX 한 줄) 과 **하단 블록**(기능 카테고리) 로 나누고 그 사이에 `SplitPane orientation="horizontal"` 적용.
- `storageKey="portfolio-split-main"`, 기본 비율 예 `35`(상단) / 나머지 하단, 범위 `min=20, max=65`.
- 상하 분할이 들어가므로 **페이지 전체가 뷰포트 기준 높이**를 갖는 것이 자연스럽다: 루트를 `h-[calc(100dvh - 상단바/헤더 높이)]` + `flex flex-col min-h-0` 로 잡고, 각 블록은 `min-h-0 overflow-hidden` + 내부 스크롤.
  - **주의**: 앱의 DD MASTER(`/development/workspace`)가 이미 이 방식(뷰포트 고정 + 내부 스크롤)을 쓴다. 그 구현을 참고해 일관되게. 단 PORTFOLIO는 workspace처럼 전역 폭 제약 해제까지 할 필요는 없다.
  - 페이지 자체에 세로 스크롤이 생기지 않게(내부에서만 스크롤).

## Task 3 — 세로 여유 확대 · 하단 여백
- **기능 카테고리 섹션의 세로 크기를 현재의 약 1.5배**로 키운다(상하 스플리터 기본 비율을 그렇게 잡으면 자연히 달성됨 — 상단을 줄이고 하단을 키우는 방향).
- 사용자가 "위로 좀 올려달라"고 한 취지: 상단 블록이 차지하는 높이를 줄여 **하단 카드 영역이 더 일찍 시작**하게 한다. R56에서 상단 패널을 이미 축소했으므로, 상하 기본 비율을 상단 35% 수준으로 잡아 반영.
- **하단 타이트함 해소**: 카드 그리드 컨테이너 아래에 여백(`pb-6~pb-8`)을 주고, 마지막 행 카드가 잘려 보이지 않게 스크롤 영역에 하단 패딩을 준다.
- R56에서 넣은 **고정 높이·레이아웃 점프 방지 특성은 유지**한다(카테고리 전환 시 크기 불변). 스플리터로 사용자가 조절한 비율은 유지되되, **카테고리를 바꿔도 그 비율이 흔들리면 안 된다.**

## 금지사항
- 새 npm 패키지 금지(리사이저 직접 구현). 
- `portfolio-store.ts` 어댑터 인터페이스·`PortfolioForm` 저장 로직 변경 금지.
- 인라인 카드 확장·하단 커버리지 부활 금지. 데모 익명 유지, 실데이터 커밋 금지.
- 카테고리 전환 시 레이아웃 점프 재발 금지(R56 성과 유지). `prefers-reduced-motion` 유지. 커밋 금지.

## 검증(구현 후 자기점검)
1. `tsc --noEmit && vite build` 통과.
2. 「기능 카테고리」 좌측 레일과 우측 내용 사이를 **드래그로 조절**할 수 있고, 넓히면 카테고리 영문명이 더 보인다. 새로고침 후 유지.
3. 상단 블록과 하단 블록 사이를 **위아래로 드래그**해 크기 조절이 되고, 새로고침 후 유지.
4. 하단 기능 카테고리 영역이 이전보다 **눈에 띄게 커지고**(약 1.5배), 카드 아래 여백이 생겨 답답하지 않다.
5. 카테고리를 여러 번 바꿔도 **레이아웃·비율이 흔들리지 않는다**.
6. 페이지 전체 세로 스크롤 없이 각 영역 내부에서만 스크롤된다. 모바일에서는 세로 스택으로 정상 표시된다.
