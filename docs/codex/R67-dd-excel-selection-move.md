## 0. 현재 상태 (R66까지 완료, 깨지 말 것)

- 좌측 행 머리글 `<td data-row-header>`(폭 `ROW_HEADER_WIDTH`). 클릭=행 전체 선택, **끌기=행 순서 이동**, 우클릭=메뉴.
- 범위 선택 `range: {anchor, focus}` → `rect: {top,bottom,left,right}`. 셀은 `<td data-col-id>`.
- 선택 표시: `CellSel` + `selectionShadow()`(바깥 변 2px `var(--primary)`) + 범위 채움 + 활성 셀 비움 + 우하단 `FillHandle`.
- 클립보드 복사/잘라내기/붙여넣기/내용지우기/복사한 행 삽입, TSV로 엑셀 상호 호환.
- 키보드: 방향키, Shift+방향키, Tab/Enter 이동, F2·즉시 타이핑 편집, Ctrl+D, Ctrl+Enter, Ctrl+H, Ctrl+Z/Y.
- undo/redo 50단계 스택 + 툴바 버튼.
- 열 머리글 클릭 3단 정렬(`sortBy`). 정렬 중에는 행 드래그 차단.
- `commitRecords(build)`가 저장 직전 `rankOf(before)`로 **편집 전 순서를 sortOrder에 고정**한다. 새로 만드는 모든 쓰기 경로도 이 함수를 거칠 것.
- `isFixedColumn(column)`인 열(수식·샘플관리대장 연결)은 모든 쓰기에서 건너뛴다.
- 행 순서 이동은 **담당 필터가 걸린 상태에서만** 허용(`dragEnabled`). 전체 보기에서는 금지. 이 규칙은 유지한다.

## 1. 선택 테두리를 엑셀과 같은 얇은 초록 선으로

현재 `var(--primary)`(파랑) 2px이다. 실제 엑셀처럼 바꾼다.

- 색: 엑셀 선택 테두리 초록 `#217346`. CSS 변수 `--grid-selection: #217346` 를 두고 쓰면 좋다.
- 두께: **2px → 1.5px**(얇게). `inset` box-shadow 방식은 그대로 유지하되 값만 조정한다.
- 개별 셀 선택(단일)도 같은 초록 테두리로 사각형을 그린다.
- 다중 선택도 동일하게 **바깥 변에만** 초록 선. 내부 격자에는 선이 없어야 한다(지금 방식 유지).
- 채우기 핸들도 같은 초록으로 맞춘다.

## 2. 선택 채움을 회색이 아닌 반투명으로

현재 `bg-[color-mix(in_srgb,var(--primary)_12%,transparent)]` 라 회색 블록처럼 보인다.

- 회색 계열을 쓰지 말 것.
- **지금 농도의 절반 수준**으로 낮춘다. 초록 계열의 아주 옅은 반투명으로: `color-mix(in srgb, var(--grid-selection) 8%, transparent)` 정도.
- 셀의 원래 배경(행 상태 색, 고정열 음영 등)이 비쳐 보여야 한다. 불투명 덧칠 금지.
- 활성 셀을 비워 두는 현재 규칙은 유지한다.

## 3. 화면 어느 곳을 클릭해도 선택 해제

- `document`에 `mousedown` 리스너를 달아, 클릭 지점이 표 안(`table`)이 아니면 `setRange(null)` + `setMenu(null)`.
- **예외(해제하면 안 되는 곳)**: 우클릭 메뉴(`[role=menu]`), 열려 있는 `Dialog`/`Popover` 내부(찾기·바꾸기, 날짜 선택, Select 드롭다운 포함), 삭제 확인창.
- 툴바 버튼(되돌리기·다시 실행 등)을 누를 때는 해제되어도 무방하다.
- 기존 Escape 해제는 그대로 둔다.

## 4. 데이터 없는 하단 영역 우클릭 → 빈 행 추가

- 표 아래 빈 공간(마지막 행 아래 스크롤 영역)에서 우클릭하면 메뉴가 뜬다.
- 메뉴 항목: **행 추가**. 1행씩 추가하되, 항목을 `행 1개 추가` / `행 5개 추가` 두 개로 두어도 좋다.
- 동작: `createBlankDevRecord()`로 **빈 행**을 만들어 **목록 맨 아래에 순서대로** 붙인다.
  - 엑셀에서 빈 행을 아래로 늘려 가는 것과 같은 느낌이어야 한다. 값이 채워진 채로 생기면 안 된다.
  - 순서는 `insertCopiedRows`와 같은 방식으로 최종 위치 인덱스를 `sortOrder`에 재부여한다.
  - `commitRecords`를 거쳐 되돌리기 대상이 되게 한다.
- 하단 빈 영역을 클릭하면 선택은 해제된다(3절과 일관).

## 5. 선택 테두리를 잡아 끌어 이동 (엑셀의 셀 이동)

엑셀은 범위를 선택한 뒤 **테두리에 마우스를 올리면 이동 커서**로 바뀌고, 끌어서 다른 위치로 옮긴다. 그대로 구현한다.

- 선택 사각형의 **바깥 변 위(약 3~4px 판정 영역)** 에 커서를 올리면 `cursor: move`로 바꾼다.
- 그 상태에서 끌면 이동 시작. 끄는 동안 대상 위치를 점선 사각형으로 미리 보여준다.
- 놓으면:
  - **셀 범위 이동(부분 선택)**: 원본 셀 값들을 대상 위치로 옮기고 **원본은 비운다**(잘라내기+붙여넣기와 동일). 수식·대장연결 열은 건너뛴다.
  - **행 전체 선택 상태**(행 머리글로 선택한 경우): 값 이동이 아니라 **그 행들을 드롭 위치로 재배치**한다. 즉 기존 행 순서 이동과 같은 동작이며, 여러 행을 한 번에 옮길 수 있어야 한다. 담당 필터가 걸린 경우에만 허용하는 기존 규칙(`dragEnabled`)을 지킨다.
- 이동 후 선택 영역은 옮겨진 위치를 따라간다.
- 전부 `commitRecords`를 거쳐 되돌리기 대상.

## 6. 행 머리글 드래그 = 여러 행 선택

**현재 행 머리글 드래그는 행 순서 이동인데, 이것을 다중 선택으로 바꾼다.** 행 이동은 5절(테두리 드래그)로 옮겨간다.

- 행 머리글에서 누른 채 위아래로 끌면 그 구간의 행 전체가 선택된다.
- Shift+클릭으로도 구간 확장(이미 있음)이 되어야 한다.
- 선택된 여러 행은 1·2절 규칙대로 초록 테두리 하나로 묶여 보여야 한다(고정 열·행 머리글 포함).
- 이렇게 선택한 뒤 **테두리를 잡아 끌면** 5절대로 그 행들이 통째로 이동한다.

## 7. 지켜야 할 것

- R65·R66 기능 회귀 금지: 클립보드 4종, 복사한 행 삽입, 키보드 조작 전체, undo/redo, 열 정렬 3단 토글, 채우기 핸들, Ctrl+D/Ctrl+Enter/Ctrl+H, 담당 필터별 부분 재배치가 다른 담당 자리를 보존하는 로직(`ordered`/`globalOrdered`), 신규 접수 행 상단 고정(`recentIntakeRows`), 인라인 편집, 열 너비 조절, 그룹 접기/펴기.
- 표 전체 `select-none` 유지(드래그 시 브라우저 텍스트 선택 방지), 인라인 편집기 입력요소는 예외.
- 편집 시 순서 고정 규칙(`commitRecords` → `rankOf`) 유지.
- 검증: `npm run build`(= `tsc --noEmit && vite build`) 통과.
- 커밋 금지. 실데이터·단가·협력사명을 로그·주석에 넣지 말 것(공개 저장소).
- 주석은 한국어로 **왜** 를 적는다. 기존 스타일(세미콜론 없음, 2칸 들여쓰기, 한 줄 JSX 선호)을 따른다.

## 8. 권장 순서

1·2절(색·채움) → 3절(해제) → 6절(행 머리글 다중 선택) → 5절(테두리 드래그 이동) → 4절(하단 행 추가).
5절과 6절은 서로 얽혀 있으니 6절을 먼저 끝내고 5절에서 행 이동을 붙이는 편이 안전하다.
각 절이 끝날 때마다 `npx tsc --noEmit`으로 확인한다.
