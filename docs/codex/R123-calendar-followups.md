# R123~R126 CALENDAR 후속 조정

상태: 구현 완료, 빌드 통과, 순수 함수 검증 완료. 화면 확인 대기.
R122 다이어리 개편 뒤 사용자 요청으로 이어서 붙인 것들이다.

## R123 셀 배치

- 셀 높이 15% 증가. 월 보기 `min-h-36` → `min-h-[10.375rem]`, 주 보기 `min-h-80` → `min-h-[23rem]`
- 날짜 숫자를 셀 좌측 상단에 절대 배치로 고정. 휴일 이름이 옆에 붙는다
- 레인 묶음을 셀 위쪽에서 **아래쪽**으로 옮겼다. `bottom-1.5` 에 붙어 위로 쌓인다
- 아래에서부터 **출장**, 그 위에 **휴가**. 미팅은 셀 본문을 위에서부터 채운다
- 셀 여백: `paddingTop: 38`(숫자 자리), `paddingBottom: 10 + 레인수 * 22`

레인이 두 그룹이 되어 `assignLanes` 를 출장·휴가 각각 부른다.
휴가 레인은 `gridRow: lane + 1`, 출장은 `gridRow: 휴가레인수 + lane + 1` 이다.

### 색

출장은 붉은색, 휴가는 초록색 그라데이션이다.

```
trip  linear-gradient(90deg, hsl(0 74% 45%), hsl(14 90% 60%))
leave linear-gradient(90deg, hsl(160 84% 30%), hsl(150 72% 48%))
```

`calendar-events.ts` 의 `TEAM_EVENT_META` 점·칩 색도 같은 계열로 맞췄다. 범례와 HOME 팀 일정이 같이 바뀐다.
휴가의 점 표시와 셀 배경 워시는 없앴다. 이제 바가 그 역할을 한다.

## R124 반차

`CalendarEvent.half` 를 더했다. 유형이 휴가일 때만 Dialog 에 체크박스가 뜬다.

- 판정은 `isHalfLeave`. 저장된 `half` 가 기준이고, 제목에 "반차"가 있으면 그것도 인정한다.
  체크박스가 생기기 전에 넣은 건과 손으로 적은 건을 위해서다
- 하루짜리(`span === 1`)만 반쪽으로 그린다. 이틀 이상이면 무시한다
- 폭 50%, 모서리는 양쪽 다 둥글게
- 제목에 "오후"가 있거나 시작시간이 12:00 이후면 칸의 **오른쪽** 절반, 아니면 왼쪽

## R125 반복 일정

`CalendarEvent.repeat`("weekly" | "biweekly" | "monthly")과 `repeatUntil` 을 더했다.

**저장소에는 원본 1건만 둔다.** 사본을 만들면 하나 고칠 때마다 전부 손봐야 한다.
`expandRepeats(events, from, to)`(`calendar-events.ts`)가 화면에 보이는 기간 안에서만 펼친다.

- 첫 회차는 원본 객체를 그대로 돌려준다. 2회차부터는 `origin` 에 원본을 단다
- 수정 창은 `event.origin ?? event` 를 연다. 회차 날짜로 저장하면 반복 시작일이 통째로 옮겨진다
- 삭제는 반복 전체를 지운다. Dialog 에 그렇게 적어 두었다
- 매월은 같은 일자를 쓰되 그 달에 없으면 말일로 당긴다. **다음 달은 원래 일자로 돌아간다**(드리프트 없음)
- 무한 루프 방지로 420회차에서 끊는다

검증한 결과다.

```
매주 09-07 시작        → 09-07, 09-14, 09-21, 09-28, 10-05
격주                   → 09-07, 09-21, 10-05
매월 31일              → 01-31, 02-28, 03-31, 04-30
반복 종료일 09-21      → 09-07, 09-14, 09-21 에서 멈춤
2박3일 출장 매주       → 기간 길이를 유지한 채 반복
```

## R126 드래그로 날짜 이동

미팅 카드와 기간 바를 다른 날짜 칸으로 끌어 옮긴다. HTML5 드래그를 쓴다.

- 기간 일정은 **길이를 유지한 채** 통째로 옮긴다
- 놓을 칸은 테두리와 배경으로 표시한다
- **반복 일정의 2회차 이후는 끌 수 없다.** 어느 회차를 옮기는지 애매해진다. 원본(첫 회차)은 끌 수 있고 그때는 반복 전체가 옮겨진다
- `id` 가 없는 항목(옛 seed)도 끌 수 없다
- 저장은 `updateTeamEvent` 하나만 쓴다

## 하지 말 것

- `expandRepeats` 결과를 저장소에 쓰지 마라. 회차는 화면에서만 만든다
- 회차(`origin` 이 있는 객체)로 `updateTeamEvent` 를 부르지 마라. 반복 시작일이 옮겨진다
- 반차 판정에서 제목 검사(`"반차"` 포함)를 빼지 마라. 체크박스 이전 데이터가 있다
- 레인 순서를 바꾸지 마라. 아래가 출장, 그 위가 휴가다
