## A. TS.tsx — 신규 접수 상단 + 접수→처리중→완료 스텝퍼

사용자 요구: 신규 접수를 **맨 위로**, 그 다음 현황·목록·분석. 엑셀 데이터를 적절히 나눠 필수/선택 구분,
접수/처리중/완료 단계.

1. **상단 스텝퍼** — `접수 → 처리중 → 완료` 3단계를 가로 스텝퍼로(현재 각 단계 건수 배지 포함).
   21st Steppers 패턴. 현재 선택 필터 단계 강조.
2. **신규 접수 폼을 최상단 카드로 이동**(기존 하단 → 상단). 접었다 펴는 형태(기본 접힘, "+ 신규 접수" 클릭 시 펼침) 권장.
   필드 구분(라벨에 필수 표시 *):
   - **필수**: 접수일*, 요청처*, Subject(유형)*, 담당*
   - **선택**: 대상 Style No., FL No., 조직, 원인, 시험 항목, 첨부(자리)
   - **완료 시 조건부 필수**: 상태='완료'면 발주량 또는 발주 미연결 사유 중 하나(기존 규칙 유지).
   필수 미입력 시 저장 차단 + 필드 오류. 기존 저장/ localStorage 로직 유지.
3. 그 아래 **현황**(상태별 집계 + 발주량 기입률) → **목록**(DataTable, 상태 배지) → (여유 시)유형별 통계 차트.
4. 순서: 스텝퍼 → 신규접수 → 현황 → 목록 → 통계.

## B. Study.tsx — 주차별 제출 현황 캘린더

사용자 요구: 주차별 제출 현황을 **캘린더 형태**로 한눈에.

- 진행 현황 탭에서 기존 매트릭스 대신(또는 상단에) **주차 캘린더 뷰**: 가로축 주차(W29·W30·W31…),
  세로축 팀원. 각 셀 = 해당 주 제출 상태 배지(완료/진행/계획/미진행) + 주제 요약. 21st Calendars/Timelines 패턴.
- 이번 주(목요일 마감) 컬럼 강조 + 마감 알림 유지. 미제출은 눈에 띄게(빨강).
- 분류별 누적·개인 상세는 유지. 자료 라이브러리 탭은 그대로.
- 데이터는 `store.study` 그대로 사용(변경 금지).

## C. Sync.tsx — 반영 이력 타임라인

- 반영 이력(meta.history)을 표 대신(또는 표와 함께) **세로 타임라인**으로: 시각·반영자·건수·판정 배지,
  실패 건은 빨강 노드 + 사유. 21st Timelines 패턴.
- 상태 배너·대조 5종 표·이상 항목·되돌리기 버튼은 유지. 전문용어 금지 원칙 유지.
