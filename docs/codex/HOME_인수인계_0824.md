작성일: 2026-08-24  
대상 프로젝트: `C:\Users\hkpark\Desktop\fabric-rnd`

## 1. 작업 목적

HOME 화면의 기능성 포트폴리오를 11개 기능 카테고리 중심으로 재구성하고, 상단 `Overall status`부터 `담당자별 진행 현황`까지의 업무형 카드 디자인을 하단 `Work report`·포트폴리오·`Quick access`의 세련된 톤앤매너와 통일했다.

데이터 계산식, 업로드, 상세 화면 라우팅 등 업무 로직은 변경하지 않았다.

## 2. 현재 포트폴리오 최종 상태

수정 위치: `src/routes/Home.tsx`

- 보유 기능·개발 완료·검증 통과 요약 카드 삭제.
- 등록된 기능 카테고리를 동적으로 표시. 현재 기준 11개.
- 각 기능을 별도 인라인 SVG 3D 이모티콘으로 표현.
  - 냉감: 냉감 물방울·결정
  - 항균·항취: 보호 실드
  - 발열·보온: 태양
  - 온도 조절: 온도 구체
  - 땀 관리: 수분 방울
  - 형태안정·구김방지: 직물 큐브
  - 촉감: 부드러운 쿠션
  - 친환경: 새싹
  - 회복: 복원 스프링
  - 피부 마이크로바이옴: 미생물 플라워
  - 발수: 우산·물방울
- 회색 배경, 개별 카드 배경, 외곽 테두리, 카드 테두리를 모두 제거.
- 흰색 화면 위에 이모티콘과 한·영 카테고리명만 부유.
- 화면 진입 때마다 `PORTFOLIO_FLOATING_LAYOUTS` 안전 슬롯을 Fisher–Yates 방식으로 섞어 카테고리 배치를 변경.
  - 완전 난수 좌표가 아니라 겹치지 않는 고정 슬롯을 무작위 배정하는 방식.
- 세 종류의 부유 궤적을 약 5.1~7.05초 주기로 반복.
- 포인터 근접 시 마그네틱 이동과 투명도 50% → 100% 적용.
- 이모티콘 호버 효과는 회전 없이 약 5% 확대만 적용.
- 한·영 제목은 이모티콘과 간격을 두고 항상 수평 유지.
- 모션 최소화 설정에서는 부유·확대 모션을 제한.
- 우측 하단 `전체 현황 바로가기`는 `/trend/portfolio`로 이동.

### 포트폴리오 팝업

- 카테고리 한글·영문 제목.
- 카테고리 전략 또는 첫 개발 건 설명을 요약으로 표시.
- 등록·검토·진행·완료 현황 배지.
- 각 개발 건의 제목, 내용, 상태를 표시.
- 적용 원단(`fabrication`) 목록은 표시하지 않음.
- 기존처럼 개발 건 전체 상세 목록을 길게 노출하지 않고 필요한 텍스트만 유지.

## 3. HOME 상단 디자인 통일

기준 패턴은 하단 `Quick access`의 반투명 글래스 카드다.

### 공통 규칙

- `HOME_GLASS_SURFACE`: 흰색 반투명 면, 얇은 하이라이트 라인, 블러, 깊은 소프트 섀도.
- `HOME_GLASS_HOVER`: 짧은 수직 리프트, 그림자 확대, 테두리 밝기 변화.
- 그라데이션 아이콘, 저채도 컬러 글로우, 짧은 확대·회전 모션 사용.
- 회색 `muted` 면과 강한 단선 테두리 사용을 줄임.
- 기존 CSS 토큰 `--gradient-*`, `--chart-*`, 상태 색상을 우선 사용.
- 상단 배경에 넓게 번지던 파란색·보라색 대형 블러 레이어는 최종 요청으로 제거.
- 카드 깊이감은 파란색 계열 그림자 대신 무채색 소프트 섀도로 유지하고, 아이콘·데이터 라인에만 컬러를 사용.

### Overall status

- 글래스 히어로 카드로 변경.
- 진행 흐름을 암시하는 추상 SVG 곡선 그래픽 추가.
- 공정 현황을 단순 연속 막대에서 네 개의 미니 글래스 카드로 변경.
- 각 공정에 별도 그라데이션, 진행률 게이지, 호버 리프트 적용.

### 완료·접수·스케줄 KPI

- 완료와 접수는 카테고리별 강조색, 그라데이션 아이콘, 컬러 글로우 사용.
- 날짜 설정과 데이터 출처 배지는 반투명 보조 표면으로 변경.
- 스케줄의 임박·지연 블록은 좌측 굵은 선 대신 얇은 상단 컬러 라인과 소프트 섀도 사용.

### RDDA 등록 현황

- 섹션 전체를 글래스 카드로 변경.
- 헤더에 그라데이션 아이콘과 설명 추가.
- 기간 필터를 글래스 세그먼트 컨트롤로 변경.
- TOTAL·GD·국내·생산·사입 KPI를 컬러 상단 라인이 있는 미니 글래스 카드로 변경.
- 차트 배경에 반투명 패널 적용.
- 차트 TOTAL 선과 커서 색상을 하드코딩 파란색에서 `var(--gradient-1)`로 변경.
