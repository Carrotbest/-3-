# 작업지시 09 — SETTING (관리자) 화면

## 맡을 파일 (이 1개만 새로 만든다)

- `assets/js/views/setting.js`

공용 CSS는 건드리지 마라. 화면 전용 스타일은 파일 안 `STYLE_TEXT` 상수에 넣는다.

## 먼저 읽을 것

1. `assets/js/views/development.js` — 뷰 구조·스타일 주입·상세 패널 패턴
2. `assets/js/ui/widgets.js`, `assets/js/ui/table.js`
3. `assets/js/data/schema.js` — `CATEGORIES`, `STAGES`, `MEMBERS`, `FIELDS`
4. `assets/js/core/store.js` — 상태 키

## 이 화면의 성격

관리자 화면이다. **기준값이 흔들려서 생기는 문제를 여기서 잡는다.**
IA에 적힌 문제의식: 시즌·Style No. 표기가 제각각이라 집계가 어긋난다.

저장은 `localStorage['fabric.settings']`에 JSON으로 한다. 서버는 없다.
읽을 때 저장된 값이 있으면 쓰고, 없으면 `schema.js`의 기본값을 쓴다.

## 서브 라우트

`#/setting/<sub>` — `standards`(기본) / `users` / `alerts` / `history`
상단 탭(`.tabs`)으로 전환하고, 탭 전환이 곧 라우트 이동이 되게 한다.

## 1. 기준값 (`standards`)

6개 목록을 좌측 리스트 + 우측 편집 영역으로 나눈다:
**조직 / 가공 / 시즌 / 카테고리 / 담당자 / Buyer**

- 각 항목: 값 · 표시명 · 사용 건수 · 상태(사용/비활성)
- **삭제 버튼을 만들지 마라.** 사용 중인 값은 지워지지 않고 **비활성화만** 된다.
  비활성 항목은 흐리게 표시하고 `비활성` 배지를 단다. 되돌리기 버튼을 둔다.
- 사용 건수는 `store.get().records`에서 해당 값을 쓰는 건수를 세어 표시한다.
- 시즌 항목에는 **표기 정규화 미리보기**를 붙인다:
  입력칸에 `SP27`을 넣으면 `SS'27`로 바뀌어 보인다는 것을 보여준다.
  `core/format.js`의 `normalizeSeason()`을 그대로 쓴다. 직접 구현하지 마라.
- Style No. 패턴은 `checkStyleNo()`의 정규식을 문자열로 보여주고,
  현재 데이터 중 패턴에 어긋나는 건수를 함께 표시한다.

## 2. 사용자·권한 (`users`)

- `MEMBERS` 목록 표: 이름 / 역할 / 권한 / 상태
- 권한 3단계: `조회` / `등록·처리` / `관리자`. select로 바꿀 수 있게 한다.
- 각 권한이 무엇을 할 수 있는지 표로 명시한다 (조회·TS 등록·기준값 변경·되돌리기).
- 관리자를 0명으로 만들 수 없다 — 마지막 관리자의 권한을 내리려 하면
  `관리자는 최소 1명이 필요합니다.` 오류를 필드 아래에 띄우고 값을 되돌린다.

## 3. 알림 규칙 (`alerts`)

on/off 토글 + 기준일 입력. 규칙 4가지:

| 규칙 | 기본값 |
|---|---|
| 납기 임박 알림 | 켬 · 3일 전 |
| 납기 초과 알림 | 켬 · 당일 |
| TDS 미반영 알림 | 켬 · 7일 |
| STUDY 마감 알림 | 켬 · 목요일 1일 전 |

토글은 `<button role="switch" aria-checked>`로 만든다. 체크박스를 숨기고 꾸미지 마라.

## 4. 변경 이력 (`history`)

- 기준값·권한·알림 규칙의 변경 기록 표: 시각 / 변경자 / 항목 / 이전값 → 새값
- 이 화면에서 값을 바꾸면 이력에 한 줄이 쌓인다 (localStorage에 함께 저장).
- 비어 있으면 `아직 변경 이력이 없습니다.`

## 주의

- 모든 입력은 저장 버튼을 눌러야 반영된다. 입력 즉시 저장하지 마라.
- 저장 후 `저장했습니다` 안내를 3초간 보여준다 (`alert()` 쓰지 마라).
- 되돌릴 수 없는 동작은 이 화면에 없어야 한다.

## 확인

`node --check assets/js/views/setting.js` 와 import 경로만 확인하고 보고한다. 브라우저 확인은 하지 마라.
