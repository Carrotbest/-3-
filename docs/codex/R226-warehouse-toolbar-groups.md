# R226 창고보관 탭 버튼 줄 묶음 정리

## 상태

미착수. R224와 R225가 워킹트리에 들어가 있고 빌드까지 통과했다. **그 작업을 되돌리거나 다시 만들지 마라.**

이번 작업은 배치와 색만 바꾼다. **동작, 조건, 권한, 핸들러는 한 글자도 바꾸지 마라.**

## 배경

창고보관 탭 버튼이 아홉 개가 한 줄에 나열되어 있다. 무엇이 자주 쓰는 것인지 구분이 안 되고, 출고 요청과 출고 확정이 붙어 있다.

출고 확정은 창고팀이 컷팅을 마친 뒤 누르는 동작이다. 지금 검정 채움이라 줄에서 가장 강해 보인다. 요청하는 쪽이 잘못 누를 여지가 있다. 요청과 확정을 갈라 놓고 색으로도 구분한다.

버튼을 숨기거나 메뉴로 접지 않는다. 사용자가 전부 그대로 두기로 정했다.

## 바꿀 곳

`src/routes/Warehouse.tsx` 1521행부터 1531행까지다. 창고보관(`WAREHOUSE`) 탭 버튼들이 한 줄에 이어져 있다.

**다른 탭(`READY`, `HISTORY`)의 버튼은 건드리지 마라.** 1526행 폐기 버튼은 `READY`와 `WAREHOUSE` 양쪽에 걸쳐 있으니 조건식을 그대로 두고 자리만 옮겨라.

## 목표 배치

왼쪽부터 이 순서다. `│`는 세로 구분선이다.

```
[입고 확인] [입고 확인 취소]  │  [출고 요청]  │  [출고 확정]  │  [소진] [폐기] [입고 대기로] [전체 확인 처리]   [미확인 N건]
```

네 묶음이다.

| 묶음 | 버튼 | 뜻 |
|---|---|---|
| 입고 | 입고 확인, 입고 확인 취소 | 가장 자주 쓴다 |
| 요청 | 출고 요청 | 요청하는 쪽 동작 |
| 확정 | 출고 확정 | 창고팀 동작. 되돌리기 어렵다 |
| 기타 | 소진, 폐기, 입고 대기로, 전체 확인 처리 | 가끔 쓴다 |

`미확인 N건` 토글은 지금처럼 오른쪽 끝에 둔다.

**출고 요청과 출고 확정 사이는 다른 구분선보다 넓게 띄운다.** 붙어 있어서 잘못 누르는 것을 막는 것이 이번 작업의 목적이다.

## 구분선

버튼과 같은 줄에 들어가는 세로선이다. 이런 모양으로 만든다.

```tsx
<span aria-hidden="true" className="h-5 w-px shrink-0 bg-[var(--border)]" />
```

묶음이 통째로 사라질 수 있다. 예를 들어 출고 요청 권한만 있고 창고 편집 권한이 없는 사람은 입고 묶음과 확정 묶음이 통째로 안 보인다. **그때 구분선만 덩그러니 남으면 안 된다.**

각 묶음을 `<div className="flex shrink-0 items-center gap-2">`로 감싸고, 그 묶음 안 버튼이 하나라도 보일 때만 묶음과 그 앞 구분선을 그려라. 조건은 이미 각 버튼에 붙어 있는 것을 그대로 쓴다.

- 입고 묶음, 확정 묶음, 기타 묶음: `tab === "WAREHOUSE" && canEditScope`
- 요청 묶음: `tab === "WAREHOUSE" && canRequestOutbound`

버튼 하나하나에 붙은 조건식은 지우지 말고 그대로 둔다. 묶음 조건은 그 위에 덧씌우는 것이다.

## 색

| 버튼 | 지금 | 바꿀 것 |
|---|---|---|
| 입고 확인 | 초록 채움 | **그대로 둔다** |
| 입고 확인 취소 | `variant="outline"` | 그대로 |
| 출고 요청 | `variant="outline"` | **파랑 채움으로 올린다** |
| 출고 확정 | 기본 채움(검정) | **호박색 테두리 버튼으로 낮춘다** |
| 소진, 폐기, 입고 대기로 | `variant="outline"` | 그대로 |
| 전체 확인 처리 | `variant="ghost"` | 그대로 |

출고 요청은 요청하는 쪽의 주 동작이라 눈에 들어와야 한다. 입고 확인의 초록과 구별되는 파랑을 쓴다.

```
className="bg-sky-600 text-white hover:bg-sky-700 disabled:bg-sky-600/40 dark:bg-sky-500 dark:hover:bg-sky-600"
```

출고 확정은 채움을 걷고 테두리만 남긴다. 창고팀에게는 보이되 줄에서 가장 강한 버튼은 아니게 한다. `variant="outline"`에 이것을 더한다.

```
className="border-amber-300 bg-amber-50 text-amber-800 hover:bg-amber-100 dark:border-amber-500/40 dark:bg-amber-500/10 dark:text-amber-200 dark:hover:bg-amber-500/20"
```

출고 확정 버튼의 `title`에 창고팀 동작임을 적는다. 지금은 고르지 않았을 때만 문구가 있다. 골랐을 때는 `창고팀이 컷팅을 마친 뒤 누릅니다`를 보인다.

## 하지 말 것

- 버튼을 지우거나 드롭다운 메뉴로 접지 마라
- 버튼의 `onClick`, `disabled`, 권한 조건을 바꾸지 마라
- 아이콘을 바꾸거나 빼지 마라
- 라벨을 바꾸지 마라. R225에서 이미 정했다
- `READY` 탭과 `HISTORY` 탭 버튼을 건드리지 마라
- R224와 R225가 만든 코드를 되돌리지 마라
- 줄 전체를 감싸는 바깥 `div`의 클래스(`overflow-x-auto`, `p-2` 등)를 바꾸지 마라. 좁은 화면에서 가로 스크롤이 살아 있어야 한다
- 화살표(`→`)와 가운뎃점(`·`)을 화면 문구에 쓰지 마라
