HOME 대시보드 변경

완료·신규

각 카드에 달력 버튼을 추가했습니다. 사용자가 시작일과 종료일을 직접 설정하면 카드 건수와 상세 목록이 함께 갱신되며, 선택 기간은 해당 브라우저에 저장됩니다.

스케줄

기존 지연경보를 스케줄로 변경했습니다. 진행 중 개발 건을 납기 임박(D-7 이내)과 납기 지연(D+)으로 나누고 담당자·플래너·Style No.·Due Date를 표시합니다.

상세 데이터

완료는 Received Date, 신규는 Request Date, 스케줄은 Due Date를 기준으로 상세 팝업을 제공합니다.
