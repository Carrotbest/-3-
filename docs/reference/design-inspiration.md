# 디자인 레퍼런스 사이트 (사용자 제공 · 2026-08-04)

대시보드 전체 디자인·스타일·동적 요소의 참고 기준. 화면 다듬기(refine) 단계에서 활용한다.
기본 팔레트·토큰은 `docs/reference/index.css`(shadcn 라이트)를 유지하고, 아래는 "느낌·인터랙션" 참고.

| 사이트 | 성격 | 우리 프로젝트에서 뽑아 쓸 것 |
|---|---|---|
| https://21st.dev/ | shadcn/React UI 컴포넌트 갤러리 (이번 프로젝트의 hero-195·border-beam 등이 여기 출처) | KPI 카드·차트·테이블·hero 등 shadcn 기반 세련된 컴포넌트 패턴, border-beam 같은 절제된 동적 요소 |
| https://superdesign.dev/ | 디자인/UI 인스피레이션 | 레이아웃 구성, 여백·타이포 리듬, 대시보드 정보 위계 |
| https://mobbin.com/discover/apps/ios/latest | 실제 앱 UI 패턴 아카이브(iOS) | 인터랙션·마이크로 애니메이션, 리스트·상세·필터 UX 패턴 |
| https://www.magnific.com/ | 비주얼/이미지 품질 레퍼런스 | 시각적 마감도·질감·디테일의 완성도 기준 |

## 적용 원칙

- **팔레트·다크/라이트는 기존 토큰 유지.** 위 사이트의 색을 그대로 베끼지 않는다(브랜드 일관성).
- **동적 요소는 절제해서.** 카운트업·링 채움·부드러운 hover·스크롤 리빌 정도. 과한 3D·네온·남발 금지.
- **정보 위계 우선.** 화려함보다 "한눈에 읽히는" 대시보드가 목표.
- 화면별 다듬기 때 이 문서의 사이트에서 해당 패턴을 구체적으로 찾아 반영하고, 무엇을 참고했는지 기록.
